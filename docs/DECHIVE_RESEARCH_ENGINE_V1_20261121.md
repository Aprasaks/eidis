# DECHIVE RESEARCH ENGINE 1.0 — 설치·검증 기록

작성일: 2026-11-21 (KST)

## 범위
사용자가 명확한 자연어 명령으로 요청한 조사만 실제 외부 검색을 시작한다. Qwen이 임의로 웹사이트 명령을 실행하거나, 개인 기억을 임의로 공개 검색 서비스로 전송하거나, 게시·결제·계정 변경을 하지 않는다.

## 실제 구현
- 기존 JARVIS Mac 앱/SwiftUI 음성 인터페이스에 JarvisResearchIntent, JarvisResearchClient 연결.
- 말하기 예시: `자비스, DECHIVE 홍보 플랫폼 조사해줘`, `자비스, 조사 현황 알려줘`, `자비스, 조사 보고서 1번 보여줘`, `자비스, 조사 1번 중단해`.
- 사용자의 명시적 요청이 있을 때에만 Bing 공개 RSS로 HTTPS 검색을 수행. 원문 수집은 검색 결과 상위 4개까지 별도 HTTPS로 요청한다. 1회 검색은 최대 8개 결과를 기록하며 24시간 최대 12건 접수, 동시 대기 6건, 실제 작업 스레드 1개만 유지한다.
- 응답 본문 최대 240KB, 원문 텍스트 최대 2,400자. 검색 색인만 읽었는지, 원문까지 읽었는지, 사이트가 접근을 거부했는지 기록한다.
- 페이지 원문은 신뢰하지 않는 외부 자료로만 취급한다. HTML 내 스크립트나 명령을 실행하거나 Qwen의 시스템 지시로 사용하지 않는다.
- 안전장치: localhost/사설 주소/IP 및 HTTP·임의 포트 차단, HTTPS 리다이렉트 재검사, DNS 주소 사전 검증, 짧은 네트워크 제한 시간. *DNS rebinding이나 원문 자체의 악성 의미까지 완벽하게 차단한다고 주장하지 않는다.*
- 연구 작업은 SQLite `research_jobs`, `research_sources`에 추가 테이블로 저장하며 현재 프로젝트·기억·사고 기록에는 자동 기록하지 않는다.
- 서버 내 단일 스레드가 DB 상태를 저장하고, 별도 작업 스레드만 외부 검색을 수행한다. 사용자 중단 시 늦게 도착한 원문은 버리고, 앱 종료로 미완료된 조사는 재실행 대신 실패로 표시한다.
- 대화 화면에 작은 스크롤형 `RESEARCH FIELD / 실제 발견 자료` 표시: 실제 제목·도메인·수집 상태·사이트가 표시한 날짜, 원문 링크. 자료가 없으면 가짜 경로나 가짜 썸네일을 표시하지 않는다.
- 발견된 페이지의 실제 이미지/동영상 미리보기, 페이지 클릭 조작, 웹 계정 로그인, 광고 발행은 1.0 범위 밖이다.
- 결과 보고서에는 각 결과의 출처 URL, 상태, 원문 발췌 또는 색인 설명, 출처 주장 날짜(있는 경우), 추가 검증 필요성을 남긴다. **원문 수집 성공이 내용의 진실성 검증 완료를 뜻하지 않는다.** 독립 출처 간 모순 대조·Qwen 합성 판단은 후속 작업에서 구현한다.

## 실제 검증
- 테스트용 일회성 DB와 임시 로컬 HTTP 서버에서 검색어 `Python official documentation`을 실제 Bing RSS에 전송.
- 검색 결과 8건, 실제 읽을 수 있었던 문서 3건: `https://www.python.org/`, `https://www.python.org/downloads/`, `https://docs.python.org/`.
- `https://namu.wiki/w/Python`은 원문 접근이 실패했으며 `unavailable`로 기록. 보고서 최종 상태는 성공이 아닌 `partial`.
- 결과·출처 URL·상태를 SQLite에 저장한 후 다시 열어 복원되는 것까지 검증. 실제 개인 DB에 테스트 정보를 넣지 않음.
- 외부 URL 안전 제한(127.0.0.1, link-local, localhost, 임의 포트, HTTP), 검색 결과가 없는 상태, 성공/실패/중단, 늦게 도착한 응답 버리기, 24시간 제한, 무단 외부 입력 거부를 테스트.
- Python 자동 회귀 테스트 255개 통과, 네이티브 Swift 라우팅 스모크·Swift 앱 빌드 통과. 실사용 Mac 음성·장시간 운영 품질은 추후 검증.
