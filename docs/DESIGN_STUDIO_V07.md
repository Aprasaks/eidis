# JARVIS Design Studio v0.7 — 사용자의 말로 화면 설정 만들기

> 2026-11-13: 로컬 설계 엔진과 외부 AI **선택적 어댑터** 구현. API 연결을 켜지 않은 상태에서도 로컬 시안 생성과 미리보기/적용/취소가 동작합니다.

## 사용할 수 있는 경로

1. 자비스 화면에서 "작업 공간 열기" → "화면 다시 설계" → "✦ 자연어로 새 시안 만들기"를 엽니다.
2. "더 어둡고 간결하게, 여백을 넓혀"를 입력합니다.
3. 기본값 **로컬 설계 · 무료** 상태로 "새 시안 4개 만들기"를 누릅니다.
4. 새로 등장한 4개를 눌러 현재 대시보드의 배경·강조색·배치·정보 밀도·원형 효과를 변경해 봅니다.
5. "선택한 디자인 적용" 또는 "이전 화면으로"를 누릅니다.
6. 하단 명령창에 "자비스, 대시보드 더 어둡고 간결하게 바꿔"라고 입력하면 로컬 설계안을 자동 생성합니다.

## 반드시 구별해야 하는 것

- 기본 **로컬 설계**는 키워드+사전 검증된 색상군+배치 규칙으로 새 설정을 조합하는 결정적 규칙 엔진입니다. AI 모델이 아닙니다.
- **외부 AI**는 OpenAI Responses API에 디자인 요청 문장을 전달해 안전한 구조화 JSON으로 네 개를 설계하도록 한 옵션입니다. 기본값 OFF, 실제 계정/API 키를 설정해야 하고, 현재 계정으로 호출 성공 여부는 미검증입니다.
- 외부 AI는 **API 키 설정 AND JARVIS_ENABLE_DESIGN_API=1 AND UI에서 매 요청 동의**를 모두 만족해야만 호출합니다. 구독료와 별개로 API 사용료가 발생할 수 있으므로 원치 않으면 켜지 마세요.
- 이미지를 생성하거나 자유로운 HTML/CSS/자바스크립트 코드를 생성하지 않습니다. 화면에서 동작 가능한 안전한 디자인 토큰만 생성/검증합니다.
- '생성된 스타일'은 현재 실행 세션의 브라우저 화면에만 적용합니다. 실제 배포/시스템 환경을 수정하지 않으며, 새로고침 후 원래 디자인으로 돌아갑니다.

## 외부 AI를 명시적으로 켜려면 (선택)

**API 비용이 발생할 수 있습니다. 다음 설정은 사용자가 직접 명시적으로 승인하기 전에는 적용하지 마세요.**

로컬 실행 프로세스의 환경 변수:
- `OPENAI_API_KEY`: 사용자가 발급한 별도 API 키. 코드에 직접 기록하거나 GitHub에 커밋하지 마세요.
- `JARVIS_ENABLE_DESIGN_API=1`: 원격 설계 API 허용 스위치.
- `JARVIS_DESIGN_MODEL`: 선택적 모델 이름 (기본 `gpt-6-luna`).

앱에서 **외부 AI 설계**를 선택하고 전송 동의 체크박스까지 눌러야 API 요청이 발행됩니다.

## 안전 및 검증

- 서버는 127.0.0.1에만 연결되고, 출처(origin) 검사 및 본문 크기 제한을 합니다.
- 디자인 요청은 3~320자로 제한하고, 원격 요청에서 모델 출력 토큰을 제한하며 자동 재시도하지 않습니다.
- 디자인 결과는 명시된 필드와 6자리 HEX 색상만 허용합니다. 문자 대비 7:1, 포인트 색 대비 3:1 이상을 검사합니다.
- 원격 모델이 반환한 HTML, 실행 코드, CSS, 외부 URL 등을 브라우저에 삽입하지 않습니다. DOM은 textContent 등 안전한 방식으로 구성합니다.
- 서버 활동 이력에는 **설계 요청 문장이나 모델 응답 본문을 기록하지 않고** 설계 요청 종류만 남깁니다. 외부 API 사업자는 사용자가 명시적으로 보낸 요청을 처리하므로 개인정보/비밀을 입력하지 마세요.
- 모델 API가 실패할 경우 AI로 생성한 것처럼 로컬 시안을 대신 보여주지 않고 실패를 표시합니다.
- 실제 AI 요청의 성공은 자격 증명과 유료 호출을 하지 않았으므로 검증하지 않았습니다.
- 별도 프로젝트 파일, GitHub 배포, Mac 시스템 설정/권한, 사용자 문서/파일을 직접 변경하지 않습니다.
