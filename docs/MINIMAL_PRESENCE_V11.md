# JARVIS 최소 대기 화면 — UI 1.1

## 화면의 새 기준
- 평상시: 검은 은하의 깊이감 + 작은 입자 원 + '무엇을 도와드릴까요?' + 하단 명령 입력창.
- 화면에 'JARVIS' 로고, 버전, 연결된 기능 카드, 메모리 수 등 기술 상태 표시를 노출하지 않음.
- 우측 위: **실제 로컬 이벤트만** 작은 터미널로 표시. 빨리 흘러가는 *가짜 로그*를 생성하지 않음.
- 터미널 오른쪽 위 확장 버튼을 눌러 디버깅할 때만 로그/필터/화면 지우기를 크게 볼 수 있음.
- 대시보드는 명시적으로 열어야만 보임. 내부에는 '기억 / 화면 / 디자인' 3개의 진입 버튼만 있음.
- '대시보드 닫아', '작업 공간 닫아'라고 요청하면 다시 최소 대기 화면으로 복귀.
- 모바일: 입자 원과 문구를 세로 배치하고 구석 로그는 더 작게 유지.

## 기능 경계
- 기억·디자인 시안·브라우저 화면 미리보기·선택적 AI 분석 연결은 삭제하지 않음.
- 로컬 명령 처리만 즉시 실행됨. 자연어 AI 대화/화면 이해는 여전히 실제 모델 연결 및 권한 검증 필요.
- 터미널은 localhost 앱 메타데이터+현재 브라우저 세션 이벤트를 보여줌. macOS 전체 프로세스 로그가 아님.
- 화면의 별자리/은하 표현은 CSS와 현재 입자 캔버스로 표시함. 새로운 외부 이미지 요청이나 CDN 사용 없음.
- 한국어 글꼴은 설치된 시스템 글꼴 우선. 폰트 파일 다운로드나 번들링 없음.
- 사용자 Mac 실기기에서 음성/화면/손쉬운 사용 권한을 테스트하지 않았음.

## 테스트
- Python 코어/명령 테스트: 대시보드 열기 및 닫기.
- UI 계약 테스트: 로고/버전/연결 카드 제거 및 필요한 명령/화면 DOM 후크 유지.
- Playwright Chromium: 1440×900 데스크톱 + 390×844 모바일에서 대기 화면, 호출, 작업 공간, 디자인, 기억, 화면 분석 폼, 한 장 분석 동의 기본값, 작은 로그/확대, 명령으로 닫기, 수평 넘침 검증.

변경 내용이 실제 Mac에서 보이는 모습은 Chromium과 다를 수 있으며, 실기기 화면은 별도 검증 대상.
