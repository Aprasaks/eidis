# JARVIS — 시스템 날짜 및 실제 음성 응답 속도 개선

작업일: 2026-11-21 / Mac 현장

## 제보와 진단
- 사용자 실제 질문 `오늘은 무슨 요일이야?`에 자비스가 `2026년 5월 24일`이라고 잘못 답함.
- Mac 시스템은 실제 `2026년 11월 21일 토요일`, `Asia/Seoul`로 정상 표시.
- 기존 자유 대화는 Qwen의 도구 선택 프롬프트와 로컬 모델 응답 **전체**를 동기적으로 기다린 뒤 한 번에 표시.
- 같은 Qwen 9B 모델 독립 측정: 짧은 요청(도구 없음) 약 2.09초, 도구 경유 요청 약 4.76초; 모델 최초 준비 포함한 스트리밍 호출 약 10.9초. 모델이 이미 로딩된 후 동일 짧은 호출은 약 0.71초.
- 별도 Mac Swift Ollama NDJSON 재시험: 모델 준비 상태에서 화면 첫 문장까지 약 0.14초, 전체 답변 종료까지 약 0.65초(마이크 ASR, TTS 미포함).

## 변경
1. `JarvisLocalClock`: 날짜·요일·현재 시각에 대한 엄격히 일치하는 명시적 음성 질문은 Qwen 호출 없이 `Date()`와 `TimeZone.current`에서 즉시 응답. `DateFormatter`는 한국어·그레고리력을 사용하고 실제 Mac 시간대/오프셋을 표기. 임의 오늘 날짜를 코드에 하드코딩하지 않는다. 관련 없는 질문은 일반 대화로 처리하며, Qwen 호출에서도 현재 Mac 시각을 동적으로 시스템 컨텍스트에 삽입한다.
2. `JarvisConversationSpeedRoute`: 일반 잡담/생각 질문은 도구 선택 스키마를 보내지 않는 빠른 로컬 대화 경로로 전환. 브라우저·파일·검색·프로젝트·대시보드 등 행동을 암시하는 명령은 기존 감사 가능한 도구 라우팅 경로를 유지. **통합 테스트에서 정확한 경계에 대한 실사용 추가 검증이 필요하며, 자유 입력에서 새로운 유형의 명령이 언제나 안전하게 분류된다고 주장하지 않음.**
3. `JarvisOllamaTextStream`: 대화 전용 `URLSession.bytes(for:)`로 Ollama NDJSON 스트림을 받아 첫 글자가 나타날 때부터 화면에 임시 답변 표시. 완전한 완료 응답을 확인한 후에만 대화 기록에 저장. 도구 호출이 응답에 섞이거나 JSON이 잘못되거나 취소된 경우 성공으로 인정하지 않는다. 응답 최대 길이·줄 수·입력 크기 제한을 둔다.
4. 전체화면, 왼쪽 대화 패널, 라이브 대화 패널에서 임시 작성 중인 텍스트를 표시하고 완료/취소 시 정리한다.
5. `JarvisLocalModelWarmup`: 사용자가 Mac에서 앱을 실행하면 비동기 로컬 Ollama `/api/generate` 무프롬프트 요청으로 모델 가중치만 준비. 질문이나 기억을 전송하지 않고, 오픈AI/유료 API를 호출하지 않는다. 모델 준비 실패도 로컬 도구 실행을 막지 않는다. 대화 시 `keep_alive` 30분으로 변경. 앱의 전력 절약 및 고온 상태에서는 예열하지 않는다.
6. 실제 음성 캡처 최종화, Ollama 답변 텍스트, 음성 합성 시작 시간 경과를 개인정보 없이 `NSLog` 기록. TTS 서비스는 기존 설정을 유지한다.

## 범위와 주의
- Mac 시스템 시계/시간대가 잘못 설정되어 있으면 그대로 잘못 응답한다. Mac 기준의 현재 날짜/시간이지 네트워크로 별도 인증한 시간은 아니다.
- 모델 예열은 로컬 메모리에 약 수 GB를 더 쓰므로, 다른 작업이 많으면 macOS의 메모리 상황을 관찰해야 한다. 30분간 모델을 쓸 일이 없으면 Ollama가 내려놓을 수 있으며, 다음 호출은 느려질 수 있다.
- 스트리밍 초반 텍스트는 **작성 중인 임시 답변**이며 최종 검증된 사실이 아니다.
- Mac 사용자 실제 음성 왕복 지연(마이크 권한, 음성 인식, ElevenLabs 네트워크, 음성 재생 완료)은 별도로 재현/측정하지 않았다. 실제 TTS 체감 속도는 미검증이다.
- 기존 개인 자료, GitHub/Vercel 조회 주기, 브라우저/연구 엔진, 금빛 코어 영상, ElevenLabs API 키는 변경하지 않았다.

## 시험
- `macos/tests/clock-speed/main.swift`: 고정된 날짜로 2026-11-21 토요일/시각 검증과 Mac 현재 시계 동적 확인; 의도 분류의 관련·부정·오명령 회귀 검사.
- `macos/tests/clock-speed/stream-live.swift`: 실제 로컬 Qwen을 사용해 NDJSON 스트리밍 초반 표시 및 완료 검증. 외부 모델 또는 API 키 불필요. GitHub CI에서는 실제 로컬 Ollama가 없어 실행하지 않음.
- Python 전체 회귀 및 Swift 앱 빌드, 앱 서명·설치, 기존 데이터베이스 보존과 실제 API 연결 확인 후 커밋 예정.
