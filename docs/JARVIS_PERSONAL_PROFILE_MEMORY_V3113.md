# JARVIS v3.11.3 — 사용자 프로필 장기 기억 (Mac 로컬)

## 작업 범위

- 기존 SQLite DB `~/.jarvis-lab/memory.sqlite3`에 `personal_profile` 테이블을 **추가**. 기존 `memories`와 프로젝트·작업·실행 기록은 절대로 초기화하거나 덮어쓰지 않음.
- 사용자가 앞서 제시된 초기 프로필 초안을 승인한 이후, 로컬 Mac DB에 **비민감 프로필 8개 항목**을 명시적 승인 출처(`user_approved_seed`)로 저장. 사용자의 이름은 DECHIVE라는 호칭만 사용. 법적 이름/생년월일/비밀번호/토큰은 기록하지 않음.
- 별도 프로젝트/대화 기록 테이블을 생성하지 않고 기존 기록 그대로 보존.
- 프로필 항목: `display_name`, `identity`, `values`, `working_style`, `communication_style`, `environment`, `assistant_role`, `goals`.
- GET `127.0.0.1:8765/api/profile`: 확정 프로필 조회. POST `/api/profile`: 명시적으로 요청된 단일 프로필 항목 수정. POST `/api/profile/forget`: 개별 항목 삭제. 서버의 loopback Host/Origin 확인과 허용된 필드/길이 검사 유지.
- Qwen3.5 맥 로컬 대화는 매 대화 요청마다 확정된 저장 프로필을 읽어 **참고 컨텍스트**로 사용. 조회 실패 시 기억이 있다고 추측하지 않음. 화면의 텍스트/웹페이지가 프로필 내용을 임의로 바꾸지 못함.
- 직접적인 “나에 대해 뭘 기억해?” 명령은 저장된 항목을 그대로 읽고, “내 작업 방식은 ... 기억해줘” / “내 작업 방식 기억 지워” 명령으로 항목별 수정·삭제 가능. 구체적 항목 없는 삭제 요청은 실행하지 않고 구체화를 요청함.
- 전체 대화 자동 저장, 무단 성향 추론/자동 프로필 변경, 마이크 기록 보존 없음. 개인정보 및 일부 인증 토큰 패턴은 저장 거부.
- 긴 회상은 원래 코어를 가리지 않는 왼쪽 스크롤 영역에 표시. 하단 마이크/키보드, Aria/TTS와 Esc 종료 및 전역 단축키는 보존.

- 초기 프로필 8건 저장, `confirmed=1`, `source=user_approved_seed` 실제 API 재조회 확인. 기존 프로젝트 2개, 작업 25건, 기존 자유 메모 0건 보존.
- v3.11.2에서 금빛 코어에 “나에 대해 뭘 기억해?” 입력 → 8개 프로필 회상 확인.

## 개인 데이터 취급과 한계

- SQLite 사용자 프로필과 Qwen 모델 입력은 로컬 Mac에서 처리한다. 그러나 **Aria 음성 합성**을 선택한 경우, 자비스가 말하는 응답 텍스트가 ElevenLabs로 전송되어 크레딧이 사용될 수 있다. 개인 정보가 포함된 음성 응답에는 주의가 필요하다.
- 사용자의 비밀번호, API 키 또는 민감 데이터는 개인 프로필에 저장하지 않는다. 이 검사는 일반적 패턴에 대한 방어선이지 완전한 개인정보 탐지 기능이 아니다.
- 현재는 ‘사용자 프로필 기억’이 연결된 상태다. 전체 대화의 자동 요약/장기 저장, 작업 실행 결과의 자동 장기 기억, 유사도 기반 검색, Obsidian/Notion 동기화는 **아직 미구현**이다.
- 새 프로필 명령의 실제 한국어 음성 인식 정확도는 사용자의 마이크로 최종 확인해야 한다. Mac 앱의 텍스트 입력 및 Qwen 연동 경로는 실기기에서 검증했다.
