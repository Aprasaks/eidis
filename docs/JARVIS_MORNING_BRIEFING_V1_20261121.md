# MORNING BRIEFING 1.0 — 2026-11-21

## 사용법
작은 코어에서 마이크를 켜거나 전체화면에서 "자비스, 오늘 아침 뉴스 브리핑해줘"라고 요청한다. 실제 수집을 시작하며 작은 코어는 기존 대화를 보존해서 전체화면 작업 모드로 확장한다. 왼쪽 대화, 오른쪽 뉴스 보드. "뉴스 브리핑 닫아" 또는 보드의 닫기 버튼으로 닫는다.

## 데이터
- 연합뉴스 종합, 국제, 경제 RSS; BBC World; OpenAI 공식 뉴스 RSS; Google 공식 AI 블로그 RSS. 실제 6개 피드.
- 조회 시작 시각 기준 직전 24시간. 날짜 없음, 미래 날짜, 범위 밖 자료, 다른 발행처 도메인 링크 제외. 일반 인사/부고/게시판/동정 제외.
- 카테고리별 최신 최대 3건, URL과 제목 중복 방지. 분야별 주요도 판단이나 사건 단위 교차 검증은 하지 않는다.
- 기사 제목·짧은 RSS 소개문·발행처 표시 시간·수집 시간·실제 URL. 원문 본문 수집 또는 독립 사실 검증 완료로 표시하지 않는다. 공식 AI 발표 피드에 새로운 자료가 없으면 해당 기간 자료 없음으로 표시한다.
- 음성은 카테고리별 제목 중심 요약이며 Qwen이 제목/날짜를 생성하지 않는다.

## 실행 경계
- 사용자가 명시적으로 요청할 때만 외부 네트워크 접근. 지정된 고정 공개 RSS URL만 요청, 사용자 텍스트/개인 정보 전송 없음.
- 최대 4개 병렬 피드 조회, 응답 크기 제한, 공개 HTTPS 검사, XML DTD/ENTITY 거절. DNS 재바인딩에 대한 완전한 네트워크 격리는 아님.
- Python SQLite morning_briefings에 읽기 결과 및 상태 저장. 기존 개인 테이블의 내용을 변경하지 않는다.
- 15분 캐시, 하루 8회 새 요청, 중복 실행 제한. 실패 상태를 성공으로 표시하지 않음. 앱 종료 시 실행 중 작업 복원은 실패 상태로 전환. 이미 접수한 네트워크 작업은 대화가 닫히거나 취소되어도 제한된 수집을 마칠 수 있다.
- 임의 스케줄, 상시 마이크, 새 유료 API, 주식 주문/시세, 원문 비교 합성은 범위 밖.

## 검증
- 실제 Mac에서 6개 피드 수집 성공, Swift API 클라이언트 시험 결과 9건(종합/국제/경제 각각 3, 공식 AI 발표 0), 약 1.40초. 당시의 독립 시험 값이며 음성 왕복 시간은 포함하지 않는다.
- 임시 DB에서 실제 조회, 재사용 결과 복원, 기존 개인 기억 미변경 확인.
- Python 전체 287개 통과, Swift 앱 빌드 성공. 실제 마이크와 전체화면 시각 검증은 사용자 확인 필요.
