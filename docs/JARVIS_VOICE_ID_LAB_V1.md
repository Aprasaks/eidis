# DEKA voice ID isolated lab
- Separate arm64 Python 3.10 environment ~/.jarvis-lab/speaker/venv. SpeechBrain 1.0.3, torch/torchaudio 2.6.0, huggingface-hub 0.30.2, NumPy 2.2.6, sounddevice 0.5.1. Official speechbrain/spkrec-ecapa-voxceleb pinned revision a9f171aee6b706ea72b35dfe6d9dbd07947c2555. Offline inference, CPU 2 threads, 192-dimensional normalized embedding.
- Synthetic Mac voices Yuna/Eddy/Sandy: two distinct enrollment sentences per voice; independent sentence and short "데카" probes. Same voice sentence cosine 0.8936–0.9154, different voice 0.0965–0.3225; short probe same 0.5630–0.6259, different 0.0488–0.2353. Silence rejected. Observed embedding compute 10–34 ms after loading (not end-to-end wake latency). Synthetic results are not human error rates, no threshold selected. RMS quality check is not a speech detector.
- START_JARVIS_VOICE_ID.command runs opt-in 6 enrollment and 3 held-out sentence captures, six seconds each, explicit YES and per-capture Enter. Raw microphone samples in RAM only, no audio recording files, HF offline, no audio upload. SAVE stores only provisional normalized centroid and model revision with owner-only file mode at ~/.jarvis-lab/speaker/owner-voice-v1.npz; does not overwrite existing profile. Voice embeddings are sensitive biometric data. Delete this profile to remove enrollment. No production integration or automatic microphone capture yet.
