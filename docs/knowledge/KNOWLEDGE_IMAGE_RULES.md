# DECHIVE Knowledge 표지 제작 규칙 v1.0

적용 대상: DECHIVE.DEV Knowledge의 cover.png. 배경만 있는 그림은 완성 표지가 아니다.
실제 발행된 reference/reference-cover.png를 시각적으로 확인하고 동일한 편집 체계를 유지한다.

## 고정 요소
- 16:9 가로형. 기존 실제 원본 규격 1672 × 941px 기준.
- 좌측 상단: 작은 흰색 DECHIVE KNOWLEDGE 브랜드 문구.
- 좌측 중앙: 굵고 큰 흰색 한글 제목, 1~2줄. 제목 뒤 배경은 어둡게 유지한다.
- 제목 아래: 제목보다 작은 흰색/밝은 회색 부제.
- 우측 하단: 흰색 필기체 DECHIVE 서명.
- 어두운 남색 서재, 짙은 나무 책상, 따뜻한 황동 스탠드, 실제 사진 같은 차분한 분위기.
- 글의 개념에 맞는 소품을 우측에 배치한다. 글자와 소품은 서로 가리지 않는다.
- 실제 목록에서 약 325×183px로 축소해도 제목이 읽히고, 글자가 잘리지 않아야 한다.

## 검수
완성 PNG 자체를 이미지 보기 도구로 열고 네 가지 텍스트(브랜드/제목/부제/서명), 한글 오탈자, 잘림, 대비, 기존 스타일을 확인한다. 제목 2행도 확인한다. 축소 미리보기에서도 제목을 확인한다.
생성 도구가 문구를 누락하면 다시 생성하거나 정확한 텍스트를 배경에 조판한다. 배경만 제출하지 않는다. 실제 시각 확인이 불가능하면 pass를 기록하지 않는다.
