# JARVIS Experience UI — v0.5

> 화면 설계 및 프로토타입 구현, 2026-11-13. 이 단계는 **화면 경험**을 개발합니다. 외부 LLM/실제 프로젝트 연결·Mac 조작 완성으로 오해하지 않습니다.

## 인터랙션 원칙

- **PRESENCE:** 어두운 공간, 입자가 흩어져 있다가 "자비스?" 또는 '자비스 호출' 클릭으로 모여 비정형 원을 형성.
- **WORKSPACE:** "대시보드 띄워" 또는 '작업 공간 열기' 클릭 시 원이 왼쪽으로 이동하고 바탕이 매우 어두운 디지털 성운처럼 변화.
- **OPERATIONAL TRUTH:** `/api/status`, `/api/activity`만을 사용. 기억 수·실제 명령 종류·연결 상태를 보여주고 구독자/수익/완료한 프로젝트 등의 수치는 만들어내지 않음.
- **DESIGN LAB:** "대시보드 바꿔" 또는 '화면 다시 설계' 클릭 → Ambient, Nebula, Studio, Polar 네 가지 사전 제작 시안. 클릭 시 **일시적 미리보기**, '선택한 디자인 적용'으로 확정, '이전 화면으로'로 취소.
- **NO MISLEADING CLAIMS:** 네 가지 시안은 AI가 생성한 결과가 아니라 코드에 정의한 화면 스타일. LLM 디자인 생성은 향후 독립 기능.
- **MEMORY & SCREEN:** 이전의 로컬 기억 열람·화면 공유 미리보기 후크를 유지.
- **ACCESSIBILITY:** 버튼/라벨 제공, 모바일 2단·1단으로 재배치, 모션 감소 설정 지원, 텍스트 콘트라스트 유지.
- **SECURITY:** 외부 CDNs 없이 로컬 CSS/JS, API 데이터를 textContent로 출력. 사용자 화면/기억을 외부에 전달하지 않음.

## 체험 동선

1. 로컬 서버 실행: `python3 app.py`.
2. `http://127.0.0.1:8765` 열기 → '자비스 호출' 클릭: 입자 응집.
3. '작업 공간 열기' 클릭: 배경 전환, 대시보드 오픈, **실제** 메모리 개수와 명령 기록 확인.
4. '화면 다시 설계' 클릭: 4개 시안이 보임. 임의의 시안 클릭: 배경/레이아웃 미리보기.
5. '이전 화면으로' 클릭 시 이전 디자인 복원. 다시 열어서 시안 선택 → '적용' 클릭 시 현재 세션에서 활성화.
6. 입력창에 '기억해: 입자 원 유지' 입력 → 메모리 수와 활동 업데이트 확인.
7. 마이크/화면 공유는 브라우저 또는 Mac 사용자 권한 후 동작. 화면 공유는 로컬 미리보기이며 인지 기능 아님.
8. 1440×900 데스크톱과 390×844 모바일 폭, 디자인 시안, 화면 공유 종료, 음성의 일부 지원/권한 거부 상태 확인.

## 현재 개발과 구분할 기능

- 저장된 프로젝트 진척도, Gmail/GA4/YouTube 통계, 새 대시보드 AI 생성, 실제 Mac 화면 분석은 **미구현**.
- UI 실시간성은 localhost 상태·활동 조회 범위. 원격 데이터가 자동으로 연결된 게 아님.
- 고급 입자 그래픽과 모션은 프런트엔드 시연용. 마이크 반응·온디바이스 인식은 별도 S1 실기기 검증 필요.

## 검증
`python3 -m unittest discover -s tests -v`로 API/DOM 계약을 검증하고, `node --check web/app.js`로 JS 구문을 확인. **디자인의 실제 렌더링 품질은 브라우저 및 Mac 화면에서 별도 확인이 필요**합니다.
