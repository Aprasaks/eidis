# STOCK BOARD — 초기 조회 전용 구현 (2026-11-21)

- 작은 코어 또는 전체화면에서 "자비스, 주식 현황표 띄워봐", "미국 주식으로 바꿔봐", "삼성전자랑 SK하이닉스 비교해 봐", "오늘 거래량 높은 종목 20개 띄워봐", "주식 현황표 닫아"를 입력한다. 화면에서 1~30개 심볼을 직접 입력할 수 있다. 음성 인식 실제 검증은 별도.
- 공식 토스증권 OpenAPI JSON 명세(https://openapi.tossinvest.com/openapi-docs/latest/openapi.json) 기준 현재가, 종목명, 국내 지수, 일일 시장 거래량/거래대금/상승/하락 순위. 현재가 응답에 없는 거래량·등락률은 표시하지 않는다. 랭킹의 경우 제공된 집계 값만 표시한다.
- API 설정에서 자비스 전용 client ID/secret을 Mac Keychain에 저장한다. 같은 클라이언트의 새 토큰은 이전 토큰을 무효화하므로 다른 프로그램과 공유하지 않는다. 토스 허용 IP 등록 필요. 채팅·로그·소스·개인 SQLite에 자격증명을 저장하지 않는다.
- 고정 토스 HTTPS 호스트/읽기 경로만 허용. OAuth 외 POST, 주문 및 계좌 요청 없음. 리다이렉트 거절. 연결 전에는 확인된 시세 없음. API 실패 시 오류와 남은 시세의 기준 시각 표시. 자동 조회는 선택 시 화면을 열어둔 동안 60초 주기, 실패 또는 닫기 시 중단. WebSocket 아님.
- 현재 단계에서 장 운영 캘린더, 사용자별 관심 종목 영구 저장, 임의 한국어 종목명 검색, 섹터 및 차트, 계좌/거래는 미구현. 예제 기반 테스트는 실제 API 성공으로 표시하지 않는다. 실제 자격증명/IP 연결과 화면 및 마이크 확인 필요.
