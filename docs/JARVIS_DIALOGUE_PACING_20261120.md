# JARVIS LIVE DIALOGUE — 답변 속도·발화 정확도 조정 (2026-11-20)

## 배경
사용자가 실기기에서 실시간 받아쓰기→질문 전송 성공을 보고했지만, 응답 정확도와 대화 속도에 개선을 요청했다. 미검증 인식 품질을 검증 완료라고 기록하지 않는다.

## 변경
- 질문 자동확정 무음 대기 기본값: 2.0초 → 3.5초. 2.5~5.0초, 0.5초 간격 조절 가능. 선택은 Mac UserDefaults에 저장. 마이크 패널에서 자동 확정 자체를 끄고 Space로 수동 확정 가능.
- ElevenLabs 응답 기본 음성 속도: 기존 제공자 기본 1.0 → 0.90. 0.80~1.05에서 패널 슬라이더 조절 가능. 응답 요청의 `voice_settings.speed`에 적용하며 소환 인사 캐시는 기존 속도로 유지.
- Mac 기본 음성 대체(TTS fallback)는 기존 음성 속도 설정을 유지. 이 슬라이더는 ElevenLabs API 응답에만 적용.
- JARVIS 로컬 Qwen 시스템 지시문에 음성 인식 문장 잘림·모호성 발생 시 재확인, 알지 못하는 사실·현재 수치에 대한 추측 금지를 추가.
- 음성 입력은 기존 macOS on-device 인식과 최종 전사 프로세스를 유지하며, 원음과 임시 전사를 서버·데이터베이스에 영구 저장하지 않음.

## 한계
- 무음 대기를 늘리는 것만으로 음성 인식 정확도가 높아지는 것은 아님. 긴 멈춤에서 문장 중간 전송을 줄이기 위한 변화.
- 답변 정확성 역시 시스템 안내 개선만으로 보증되지 않음. 정보 조회의 성공, 로컬 Qwen 모델과 응답 결과는 각각 따로 검증해야 함.
- ElevenLabs 유료 요청은 발화를 생성할 때 크레딧이 들 수 있음. 단순 슬라이더 조작은 요청하지 않음.
- Mac 실제 스피커·마이크 환경에서 사용자 인식/응답 속도/명령 오동작 검증은 아직 필요.

## 검증
- `swift build --package-path macos -c debug` 성공.
- Python 테스트: 208개 통과, 수정된 음성 발화 대기와 ElevenLabs 속도 제한·기존 응답 실행 계약 포함.
- 실기기에서 직접 조작하며 재확인: 대화 자동확정, 중간 끼어들기, ElevenLabs 0.90 속도, UI 슬라이더.
