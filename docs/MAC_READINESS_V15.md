# JARVIS Mac 실기기 진단 v1.5

## 무엇을 확인할 수 있나
Mac 앱의 **진단** 탭에서 사용자가 `진단 실행`을 눌렀을 때만 검사를 시작합니다. 앱이 자동으로 마이크를 켜거나 화면을 캡처하거나 GitHub로 연결하지 않습니다.

- 앱 패키지에 마이크·음성 인식 개인정보 사용 설명이 있는지 확인
- Mac 마이크·음성 인식 권한 상태를 조회 **권한 요청 없음**
- 한국어 온디바이스 인식 지원 여부와 현재 이용 가능 상태 조회 **실제 음성 인식 성공과 다름**
- Mac 화면 기록 권한 사전 조회 **실제 화면 캡처 성공과 다름**
- 손쉬운 사용 권한 상태 조회 **다른 앱 조작 성공과 다름**
- localhost:8765 연결 확인과 SQLite quick_check 읽기 검증 **쓰기 검증 아님**
- 프로젝트 기록 개수만 조회하며 프로젝트 내용·비밀은 진단 응답에 포함하지 않음
- 도구 허용 목록과 마지막 실행 영수증의 상태만 조회. GitHub 신규 API 네트워크 요청은 하지 않음
- 결과 복사 버튼으로 민감한 원문 없이 검사 결과를 공유할 수 있음

## Mac에서 실제 확인할 순서
1. Mac에서 최신 `Aprasaks/eidis` 소스를 받아 저장소 폴더를 엽니다.
2. `START_JARVIS_MAC.command`를 실행합니다. Python 3·Swift·plutil이 없으면 필요한 항목을 알려줍니다. macOS에서 실행 가능한 개발 앱을 빌드하며 추가 API 요금은 없습니다.
3. 시작 스크립트가 실제 `GET /api/diagnostics` 응답을 받았을 때만 Mac 앱을 엽니다. 서버가 이미 다른 프로세스에 사용 중이거나 오류면 중단하고 임의의 프로세스를 종료하지 않습니다.
4. Mac 앱의 **진단** 탭 → **진단 실행**을 누릅니다. 확인됨/권한 필요/직접 테스트가 필요한 항목을 구분해서 읽습니다.
5. **음성** 탭 → 마이크로 말하기 → 시스템 권한 허용 → '자비스, 내 GitHub 프로젝트 상태 확인해' → 완료하고 명령 전달. 실제 한국어 인식 문장과 음성 응답이 정확한지 확인합니다.
6. 대상 GitHub 저장소가 없다면 **자비스** 탭의 작업 공간 → 프로젝트에서 먼저 공개 저장소 `owner/repo`를 등록합니다. 여러 프로젝트라면 이름을 지정해서 요청합니다.
7. 해당 명령을 명시적으로 보낸 경우에만 공개 GitHub API 읽기 조회가 시작됩니다. 조회 결과, 현재 커밋, Workflow 근거 및 실패 여부가 프로젝트 화면/도구 이력에 기록됐는지 확인합니다.
8. **화면** 탭 → 화면 1장 확인을 직접 눌러 캡처 및 화면 기록 권한을 확인합니다. 자동 전송/AI 분석 없음.
9. 문제가 있으면 진단 탭의 **결과 복사** 버튼으로 내용을 보존합니다. 이는 권한 상태·서버·도구 상태 등 제한된 확인 정보이며, 실제 음성/캡처 성공을 대신하지 않습니다.

## 안전/개인정보
읽기 진단은 `GET /api/diagnostics`만 요청하고 Mac/OS 권한 요청이나 외부 GitHub·AI API를 자동 호출하지 않습니다. 기존 Host/Origin 검사는 그대로 유지됩니다.
SQLite DB는 기존대로 로컬 디스크에 평문 저장되며, 이번 진단은 `quick_check`와 프로젝트 개수 등의 읽기만 수행합니다. 프로젝트명/작업 제목/대화 원문은 진단 응답에 노출하지 않습니다.
Mac 음성 입력의 GitHub 조회 명령은 외부 공개 API의 순차 요청을 위해 HTTP 타임아웃을 더 넉넉하게 설정했습니다. 외부 API 요청은 오직 실제 명령을 제출했을 때만 발생합니다.

## 완료된 검증과 아직 불가능한 검증
- GitHub Actions: Python 단위 테스트, JavaScript 구문 검사, macOS SwiftUI 컴파일·앱 패키징, Chromium 데스크톱/모바일 UI 회귀 테스트.
- 모의(mock) 응답/CI 테스트는 실제 사용자 Mac의 시스템 권한 승인과 동일하지 않습니다.
- **현재 원격 Mac이 오프라인**이어서 ChatGPT가 해당 Mac에 직접 설치하거나 마이크·화면·네트워크 응답을 실행한 것은 아닙니다.
- 실제 GitHub public API 호출, 실제 한국어 음성 인식, 실제 화면 캡처 성공은 사용자 Mac에서 위 순서로 따로 확인해야 합니다.
