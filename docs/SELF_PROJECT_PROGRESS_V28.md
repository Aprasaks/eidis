# JARVIS v2.8 — 자신의 다음 작업 기억

## 사용자 경험
- Mac **JARVIS → 음성 → 자비스 다음 할 일** 버튼을 눌러 즉시 응답을 확인합니다.
- 같은 입력은 한국어 음성이나 텍스트로도 가능합니다: **자비스, 다음 할 일 뭐야?**
- 등록된 **JARVIS eidis** 프로젝트의 SQLite 작업 기록에서 예정/진행/막힘/완료 개수와 최근 등록된 미완료 작업 최대 3건을 안내합니다.
- 외부 프로젝트를 **명시적으로** 지정하면 해당 프로젝트를 우선합니다. 예: **자비스, DECHIVE.WIKI 다음 할 일은?**
- **자비스, 프로젝트 현황 알려줘**는 전체 프로젝트의 기존 목록 응답을 유지합니다.
- **자비스, 모르는프로젝트 다음 할 일은?**처럼 정확히 식별할 수 없는 프로젝트의 상태를 자비스 것으로 추정하지 않습니다.

## 기록과 검증 경계
- 자비스 자기 프로젝트의 식별 조건: 이름 **JARVIS eidis**이면서 repo **Aprasaks/eidis**. 둘이 일치하는 저장된 프로젝트가 없으면 결과를 만들지 않습니다.
- 작업은 명시적으로 기록한 상태만 표시합니다. 최근 등록한 작업이 실제로 최우선이라는 판단은 하지 않습니다.
- 자기 현황 대답을 생성하기 위해 GitHub API, 외부 LLM, 파일 변경, Finder/브라우저 열기, AWS 배포를 실행하지 않습니다.
- 실제 배포 성공·실제 Mac 권한·실제 버튼 조작 완료 여부는 로컬 작업 메모만으로 확인할 수 없습니다.
- 음성으로 읽어주는 기능은 현재 음성 설정에 따릅니다. ElevenLabs를 사용자가 활성화하면 해당 이용 조건과 크레딧 제한이 적용됩니다. 기본 설정에서는 로컬 Mac 음성입니다.
- JARVIS는 항상 듣지 않으며 마이크로 명령하려면 사용자가 직접 시작하고 Mac 권한을 허용해야 합니다. 텍스트와 단축 버튼에는 마이크가 필요 없습니다.

## 검증
- Python 자동 테스트에서 자기 프로젝트 응답, 다른 프로젝트 우선, 전체 프로젝트 현황, 없는 프로젝트 및 외부 네트워크 호출 금지 검증.
- native macOS Swift 앱 빌드와 패키징 및 코드 서명 확인.
- 실제 실행 중인 로컬 자비스 서버로 명령을 전달해 저장된 데이터를 올바르게 읽는지 확인.
- macOS 앱 안의 물리적 클릭과 마이크 실제 발화는 별도 실사용 확인 대상.
