# JARVIS v0.9 — 화면 한 장 AI 이해 (선택적 연결)

> 상태: AI 화면 분석을 위한 API·UI 경로 구현. API 실호출 및 사용자 Mac 권한 확인은 아직 수행하지 않음. 외부 서비스 비용은 별도 설정/동의 전까지 발생하지 않음.

## 어떻게 쓰나
1. JARVIS 로컬 앱의 작업 공간 → 화면 미리보기 진입.
2. 화면 선택 및 공유 클릭 → Mac/브라우저의 허가 창에서 화면 또는 창 직접 선택.
3. 로컬 미리보기 표시(이 단계는 외부 전송 없음).
4. 질문 입력(예: 지금 화면의 오류 메시지를 해석해 줘).
5. 이번 한 장의 외부 전송 동의 체크 → AI로 현재 화면 한 장 분석 클릭.
6. API가 구성되어 있다면 한 장의 JPEG를 최대 1200px로 축소해 OpenAI Responses API로 전달.
7. 응답을 현재 화면에 텍스트로 표시. 다른 앱 클릭·수정 없음.
8. 공유 중지/화면 전환 때 결과와 동의 초기화.

## API 활성화 (사용자 승인 필요, 기본 OFF)
- OPENAI_API_KEY: 사용자가 발급한 유료 API 키(Plus 구독과 별도 과금).
- JARVIS_ENABLE_VISION_API=1: 원격 화면 분석 허용 스위치.
- JARVIS_VISION_MODEL: 이미지 입력 가능한 모델. 기본 gpt-6.1-terra (실제 계정 접근성은 미검증).
- API가 구성되어도 화면 공유 + 매 요청 동의가 없으면 화면 전송이 발생하지 않음.
- 한 서버 실행 동안 실제 공급자 호출 시도는 최대 3회. 자동 재시도 없음.

## 보안과 제한
- 서버는 localhost에서만 수신하고 Origin/Host 검사.
- JPEG 데이터 URI만 허용, 최대 1MB 압축 이미지 및 HTTP 본문 1.45MB 제한.
- OpenAI 요청 store:false; 화면 프레임과 질문을 로컬 DB·파일·활동 로그에 저장하지 않음.
- 외부 AI 공급자에 전송하면 공급자가 데이터를 처리함. 금융/비밀번호/개인정보 포함 화면은 공유하지 마세요.
- AI가 화면의 지시문을 실행하지 않도록 명시적으로 안내; 출력은 텍스트만 표시.
- 화면 한 장만 분석. 계속 보는 실시간 화면 이해 아님.
- 화면 공유 권한 및 음성 실기기 검증은 사용자 Mac에서 별도로 필요.
- 네이티브 ScreenCaptureKit 캡처 탭과 이번 브라우저 화면 공유 분석은 아직 별도.
- 키와 유료 사용 승인 없이 실제 API 호출하지 않음. CI는 모의 공급자 응답으로 테스트.

OpenAI 공식 이미지 입력 문서: https://developers.openai.com/api/docs/guides/images-vision
