# JARVIS 프로젝트 상태 — 2026-11-13

## 메인 브랜치에 적용된 기능 (v0.9까지)
- Python 로컬 명령 코어, 사용자 지정 SQLite 기억, 4개 사전 제작/로컬 문장 기반 디자인 설정.
- macOS SwiftUI 음성 입력·TTS, 수동 ScreenCaptureKit 캡처, 수동 읽기 전용 Accessibility UI 구조 검사 코드.
- 브라우저 수동 화면 공유와 한 장 AI 분석 API 경로. 원격 AI 분석은 기본 OFF·매 요청 동의 필요·세션당 최대 3회.
- CI에서 Python/JavaScript/macOS 빌드/실제 Chromium 브라우저 검사 통과.
- 사용자 Mac 실기기 권한 및 유료 AI 실호출 미검증.
