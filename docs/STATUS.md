# JARVIS 개발 상태 — 2026-11-13

## main 기준 구현
- 검은 은하형 최소 대기 화면, 구석의 작은 실제 로컬 작업 로그
- 대화 세션 RAM 맥락, 명시적 SQLite 기억, 프로젝트별 작업·수동 상태 기록
- 프로젝트 버튼에서 공개 GitHub 저장소를 한 번 확인하는 v1.3 기능
- Mac SwiftUI 음성·화면·접근성 코드 (CI 빌드만 확인, 실기기 미검증)
- 외부 LLM/비전은 기본 OFF, 키·동의 없이는 유료 요청 없음

## 현재 개발 PR — 도구 실행 v1.4
- 명시적 한국어 GitHub 조회 요청 → 대상 프로젝트 선택 → 허용 도구 검사 → 공개 API 일회성 읽기 → 현재 HEAD/Workflow 증거 검증
- tool_executions에 도구/프로젝트/권한/시작·종료/성공·실패/관측 SHA 기록
- 실행과 검증 실패를 분리하며 **GitHub 성공만으로 프로젝트 완료나 배포 성공을 주장하지 않음**
- 여러 대상이면 사용자에게 지정 요청, 부정 요청은 외부 조회 불허
- 도구 manifest와 최근 실행 이력 조회 API 제공
- 파일 쓰기·배포·삭제·셸 실행 금지. 실제 LLM의 자유 도구 선택도 미구현.
- GitHub 공개 REST API는 CI에서 모의 응답만 검증; 실기기 네트워크/비공개 저장소 인증 미검증.
