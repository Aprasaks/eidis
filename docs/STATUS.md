# JARVIS 개발 상태 — 2026-11-13

## main에서 마지막으로 확인한 범위
- 검은 은하형 최소 대기 화면, 필요할 때만 여는 작업 공간과 작은 터미널
- 로컬 명령·세션 대화 맥락·명시적 SQLite 기억
- macOS SwiftUI 음성/화면/접근성 구조 읽기 코드 (CI 컴파일 검증, 사용자 Mac 실기기 권한 검증 별도)
- 외부 AI 대화/화면 모델 경로는 기본 OFF, API 키·명시적 동의 없이는 호출하지 않음

## 현재 작업: Project Ledger v1.3
- 프로젝트, 작업 및 예정/진행/막힘/완료 상태를 SQLite에 영구 기록
- 변경 전/후 상태와 시각을 별도 감사 이력으로 보관
- "우리 프로젝트 현황 알려줘"는 로컬 저장된 프로젝트의 상태를 요약
- 작업 공간에서 프로젝트 등록/작업 추가/상태 변경 가능
- GitHub 공개 저장소 확인은 사용자의 명시적인 버튼 이후에만 요청
- 확인한 기본 브랜치 SHA, 일부 Workflow 결과와 확인 시각을 작업 상태와 별도 저장
- **GitHub CI가 성공했다고 작업 완료로 자동 변경하지 않음**
- 테스트는 현재 모의 GitHub API를 이용. 실제 GitHub API 응답 및 Mac 실기기 사용은 미검증

## 미구현

- 스스로 할 일/완료를 결정하고 실제 파일을 수정하는 자율 실행 도구
- 항상 듣기/실시간 화면 이해/아이폰·클라우드 운영
- 자동 추정에 의한 프로젝트 완료 판정
