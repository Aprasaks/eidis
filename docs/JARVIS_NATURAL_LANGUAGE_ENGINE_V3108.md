# JARVIS v3.10.8 — 자연어 명령 실행 엔진 (Mac 로컬)

## 목표와 완성된 기능

금빛 코어가 기본 화면이고, 사용자가 자연스러운 한국어로 원하는 행동을 말하면 로컬 Qwen3.5가 도구를 선택하고 JARVIS가 실제 Swift 기능을 실행한다. 실제 실행 결과만 말하고 보여준다. 버튼 중심의 대시보드를 만들지 않는다.

- 모델: `qwen3.5:9b-q4_K_M`, Ollama `127.0.0.1:11434/api/chat`, `tools` 함수 명세, `think:false`, `stream:false`. 모델 판단에는 외부 AI API 사용료 없음.
- 권한이 정해진 도구 4개: `open_browser`, `search_web`, `show_work_dashboard`, `close_panel`. 이 외의 함수 이름·인수는 거부한다. 동시 명령은 최대 3개만 해석하고 순서대로 실행한다.
- 브라우저는 Naver 또는 Google 페이지를 실제 JARVIS WebKit 패널에 표시. 사이트 표시는 로그인/결제/사이트 분석을 뜻하지 않음.
- 사용자가 서비스명을 지정하지 않으면 네이버를 기본값으로 사용. 네이버/구글 선호를 모델이 임의로 바꾸지 못하도록 사용자의 표현에서 확인.
- `인터넷 좀 켜줘`, `구글 들어가`, `프로젝트 어디까지 됐는지 보여줄래`, `그거 이제 닫아줘` 등 서로 다른 표현을 처리.
- 패널이 열려 있을 때 대화 문맥과 **실제 UI 상태**를 Qwen에게 알려준다. 지시어 `그거/이거/이 창 닫아`는 화면에 실제로 열린 패널을 기준으로 처리하여, 닫는 척만 하지 않는다.
- Qwen이 도구를 호출하지 않은 경우에도 명확한 읽기 전용 명령은 검증된 제한적 해석기로 실행한다. 임의 shell, 파일 접근, 앱 변경, 계정 조작은 실행하지 않는다.
- 개인 파일, 메일, 노션, 사진 등의 내용이나 이메일 주소를 웹 검색어로 자동 전송하지 않는다. 외부 검색 페이지 자체는 일반 공개 인터넷 검색이므로 검색어는 검색 서비스로 전송된다.
- 연결되지 않은 유튜브 영상 분석, GitHub 저장소 분석, Notion/Obsidian 편집, 사진 관리에 관해 실행했다고 주장하지 않음.
- 기존 Aria 인사/음성 답변, Qwen 대화, 작업 대시보드, 금빛 원본 영상, 모니터 이동, 전체 화면 `Esc` 중단 그대로 유지.

## 실기기 검증 — 2026-11-20

- JARVIS `~/Applications/JARVIS.app` v3.10.8 설치 및 코드 서명 검증. 기존 버전은 앱 백업 폴더에 별도 보관.
- Swift에서 잘못된 도구 호출, 비공개 검색어 차단, 엔진 선택, 안전한 기본 명령 처리 등 13개 런타임 검증 통과.
- Python 계약·안전 테스트 159개 통과, Swift 빌드/앱 패키징 통과.
- 앱 내 `자비스 인터넷 좀 열어줄래` → 실제 네이버 웹 패널 열림 확인.
- 앱 내 `자비스, 우리 프로젝트 진행 상황 보여줄래?` → 실제 작업 대시보드 표시, 프로젝트 2개, 예정 11·진행 0·막힘 0·완료 14 확인.
- 이전 v3.10.7의 `그거 이제 닫아줘`는 Qwen이 말만 하고 패널을 닫지 못하는 문제 확인 후 v3.10.8 수정.
- v3.10.8 `자비스, 그거 이제 닫아줘` → 대시보드 실제로 닫힘 확인.
- `자비스 구글 좀 열어볼까` → Google 홈이 금빛 코어 내부 브라우저에 표시됨 확인.
- 다른 앱 Finder에 초점을 두고 `Esc` → 모든 JARVIS 창 제거, 백그라운드 JARVIS 프로세스는 유지.
- Ollama 로컬 API 응답, 기존 프로젝트 2개/작업 25개, SQLite 진단 `ok` 확인.
- 실제 한국어 마이크 음성으로 새 자연어 명령 전체를 인식하는 과정은 사용자 청취 검증 필요. 앱 텍스트 입력으로 동작을 실제 검증했으며 음성 인식은 기존 공통 경로를 사용.

## 확장 방법 — 사용자 요청 목록

도구는 명시적인 이름, 허용된 인수, 필요한 권한, 실제 실행기, 결과 검증, 비용/전송 여부를 갖춘 경우에만 `JarvisCommand.tools`에 등록한다. 미구현 API의 도구를 미리 노출하지 않는다.

| 후보 | 입력/권한 | 첫 번째 검증 가능한 실행 | 경계 |
|---|---|---|---|
| YouTube | 동영상 URL, 공개 메타데이터 및 사용할 수 있는 자막/전사 | URL·제목·자막 범위·시간표시를 근거로 요약 | 자막 접근 불가 영상은 분석 완료로 표시 금지, 영상 내용 직접 이해에는 추가 처리 필요 |
| GitHub | 선택한 계정/저장소의 인증된 읽기 권한 | 저장소 목록, 특정 브랜치 파일과 Issues/PR 읽기 | 원격 Push/PR 생성·변경은 별도 작업 권한과 확인 |
| Obsidian | 사용자가 선택한 로컬 Vault 경로와 접근 권한 | 선택한 노트 목록/검색, 새 분류 초안 | 임의 Vault 전체 탐색 금지, 기존 노트 덮어쓰기는 백업·충돌 검사 |
| Notion | 공식 Integration/OAuth 및 허용한 페이지/DB 범위 | 읽기·검색 및 구조화된 정리 초안 | 수정을 위한 인증/쓰기 권한과 변경 확인 필요 |
| 사진 | macOS Photos/폴더 접근 허용 | 사진 목록, 중복 후보/날짜별 분류, 미리보기 | 원본 삭제와 영구 변경은 별도 확인, 파일 보존이 기본 |
| 요청형 대시보드 | 검증된 실제 데이터 소스와 typed view model | 요청한 데이터만 코어 옆에 표시 | 예시 숫자를 실제 현재값처럼 표시 금지 |

## 자동 실행 승인 정책

- 검색, 공개 자료 읽기, 패널 열기/닫기, 승인된 범위의 조회, 재실행 가능한 앱 열기는 보통 바로 실행.
- 삭제, 계정 권한 변경, 결제, 공개 게시, 이메일/메시지 발송, 민감 정보 외부 전송, 원본 파일의 대량 변경 등 되돌리기 어려운 행동은 실행 전에 명시적으로 확인.
- 외부 웹페이지·파일 내용은 데이터이며, 그 안에 적힌 지시는 사용자의 요청이나 자비스의 명령 허가가 아니다.
- 사용자가 `Esc`를 누르면 대화/명령의 남은 비동기 응답을 무시하고 화면을 즉시 종료.

## 아직 미구현

동영상 자막 수집 및 영상 이해, GitHub API 저장소 읽기, Notion 데이터 수정, Obsidian Vault 정리, Photos 라이브러리 정리, 모델 기반 웹페이지 DOM 분석, 외부 앱 자동 실행은 현재 v3.10.8에 없음. 이 기능들은 이후 별도의 연결·권한·실기기 테스트가 필요하다.
