# JARVIS v3.14.3 — 한 화면 고정 관제실과 명시적 전체 대시보드 호출

## 사용자 명령의 의미

- `자비스 전체대시보드 열어`, `자비스, 전체 대시보드 열어줘`, `전체 대시보드 켜줘/띄워줘/보여줘`, `전체화면 대시보드 열어`, `통합대시보드 띄워`, `관제실 열어`, 기존 `전체 현황 보여줘` → 동일한 **JARVIS / COMMAND CENTER** 통합 관제실을 연다.
- 기존 자연어 프로젝트/시스템/자료 대시보드 명령과 `원래대로 돌아가`/`전체 대시보드 닫아`는 보존.
- 유튜브 등 외부 API 미연결 데이터의 전체 대시보드를 요구하면 실제 연결 전이라고 안내하며 유사한 로컬 숫자를 대신 사용하지 않음.

## 화면 경계 및 내부 스크롤

- `JarvisCommandCenterView`의 최상단 `ScrollView`를 **제거**하고 `GeometryReader`에 맞춰 전체 HStack을 고정. 뷰포트 높이에서 하단 음성/텍스트 입력용 116pt와 상단 12pt를 제외한 범위만 관제실에 사용.
- 로컬 화면 논리 폭이 1120pt보다 좁아도 관제실 전체가 아래로 쌓이지 않도록 동일한 두 열 구조를 축소 유지. 오른쪽 세 행은 남은 화면 높이에 프로젝트/Git 43%, YouTube/Knowledge/System 35%, Recorded Events 22%로 배분. 코어는 기존 중앙→왼쪽 이동 효과 유지.
- **패널별 ScrollView만 허용:** 프로젝트, Git 목록, YouTube, Knowledge, System, LIVE CHECKS, RECORDED EVENTS. 부모 관제실 자체는 스크롤하지 않고 화면 밖 콘텐츠는 카드 내부에만 표시하거나 카드 내부 스크롤.
- 작은 화면에서도 전체 관제 영역이 길어지지 않도록 카드 높이를 가용 공간 기준으로 계산. 각 카드 내부에서 필요한 자료를 찾아볼 수 있음.
- 보이스 응답 자막을 기록 패널 아래 예약된 높이로 이동하여 RECORDED EVENTS와 겹치지 않도록 보정. 하단 대화 입력 컨트롤 계속 동작.
- 기존의 금빛 코어 영상, 로컬 데이터 원장, API 연결 방식, 백업/기억/프로필/서명은 변경하지 않음.

## 검증 — 2026-11-20 (Mac)

- Swift 앱 빌드와 Python 자동 테스트 **188개 통과**, Swift 자연어 의도 14종 테스트 통과. 띄어쓰기 없는 `전체대시보드 열어`도 인식됨.
- SwiftUI 정적 배치 이미지: **1280×720, 1512×982, 1920×1080**에서 콘텐츠 패널이 정해진 화면 높이 내에 배치됨. 실제 TV 연결 테스트는 아직 하지 않았음.
- 실제 맥에 v3.14.2를 설치하고 **텍스트 입력창에 `자비스 전체대시보드 열어`를 입력/Return 전송**하여 관제실 개방 확인. 프로젝트 2개/작업 25개, 로컬 Git 14개, 보관함 0건, 시스템 연결과 실제 조회·기록 패널이 동시 표시됨.
- 실제 스크린샷에서 기존 응답 자막과 하단 이벤트 카드가 일부 겹친 것을 발견, v3.14.3에서 자막 위치 수정. 최종 v3.14.3 설치 후 **동일한 명령을 정상 인식**하고 수정된 자막이 카드 아래에서 보이는 것을 실제 화면에서 확인.
- 수정 후 `RECORDED EVENTS`, `LIVE CHECKS`, Git 항목이 카드 내부에 보이며, 바깥 관제실의 세로 스크롤은 존재하지 않음. 다수 목록을 마우스로 실제 휠 스크롤하는 별도 인터랙션은 수행하지 않았음.
- 기존 버전은 `~/Applications/JARVIS-Backups/JARVIS-before-v3142-20261120.app`, `~/Applications/JARVIS-Backups/JARVIS-before-v3143-20261120.app`에 백업되어 있음.
- 앱 새 버전 서명 검증, 실제 설치 버전 v3.14.3, 로컬 프로젝트 2개/25건, 프로필 8건(호칭 데카이브), DB 진단 `ok` 재확인.
- 기존 v3.14.2 시험 중 접근성 자동화가 **버튼을 강제로 클릭할 때** 한 번 `EidisMac` SIGSEGV 충돌 기록이 발생함. 별도 키보드 Return 방식에서는 정상 실행됨. 비정상 종료가 UI 자동화 특성인지 실제 클릭 안정성 문제인지 단정하지 않으며, 실제 사용 중 같은 문제가 나타나면 추가 재현/조사 필요.

## 잔여 검증

- 외부 TV 실기기 연결 후 16:9·4K 글자 크기와 스크롤 인터랙션 확인.
- 자동 마이크 인식이 주변 음성에 반응할 수 있어 정확한 한국어 발화 테스트는 별도 진행.
- 로컬 Git 14개는 맥에 있는 일부 Git 작업 폴더만 센 것이며 GitHub 계정 전체가 아님. YouTube Analytics API는 아직 연결되지 않음.
