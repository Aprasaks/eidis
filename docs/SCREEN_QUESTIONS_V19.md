# JARVIS 로컬 화면 질문 v1.9

## 목표
사용자가 **화면 캡처 + 글자 읽기**를 직접 실행한 다음, 화면 속 OCR 글자를 근거로 질문할 수 있게 합니다.

## 기능
- **로컬 답변** 버튼으로 OCR 텍스트 안의 오류·실패·경고 후보 문구를 찾습니다.
- **찾아줘 / 어디** 등 질문은 OCR 텍스트 안의 관련 단어를 찾습니다.
- 그 밖의 질문은 인식된 글자의 앞부분만 정리하며, 이미지의 의미를 아는 척하지 않습니다.
- 화면에 민감한 인증 정보가 포함된 것으로 보이는 줄은 답변에 그대로 반복하지 않습니다.
- **음성으로 듣기** 버튼은 Mac 기본 TTS로 로컬 답변을 읽습니다. ElevenLabs 토글과 무관하게 무료 로컬 음성을 사용합니다.
- 새 캡처와 **지우기**는 이전 OCR 결과 및 질문 답변을 초기화합니다.

## 개인정보와 실제 검증의 경계
- 질문과 OCR 텍스트는 SwiftUI 앱 메모리에서만 처리합니다. 원본 화면/질문/답변은 Python 서버나 외부 모델, SQLite, 활동 기록에 전송 또는 저장하지 않습니다.
- 사용자가 직접 누르지 않으면 화면 캡처나 글자 질문을 실행하지 않습니다.
- 단순 규칙 기반 문자열 추출입니다. 멀티모달 AI 화면 이해가 아니므로 화면 위치, 실제 버튼 클릭 상태, 오류 근본 원인, AWS 배포 상태를 확인하거나 판단하지 않습니다.
- 화면을 캡처하거나 내용을 복사할 때는 개인정보 및 인증 정보를 화면에서 치워 두세요. 답변 내 민감정보 마스킹은 완전한 비밀탐지 보장을 의미하지 않습니다.
- Apple Vision OCR의 실제 디스플레이 캡처 및 macOS 화면 기록 권한은 사용자 Mac에서 직접 확인해야 하며, 이번 소스 빌드/합성 이미지 테스트가 이를 대신하지 않습니다.
