# JARVIS Console v1.0 — 한곳에서 보는 실행 기록

## 화면 구성
- 데스크톱(1100px 이상): 오른쪽에 고정된 터미널형 통합 패널. 중앙 작업 공간에서 최근 활동 타임라인과 명령 응답 문구를 제거.
- 모바일·작은 창: 하단 접이식 로그 서랍. 필요한 때만 펼쳐 확인.
- `전체 / 실행 / 오류` 필터, 타임스탬프, 단계별 종류 표시, 패널 접기/펼치기, 화면 지우기.
- 중앙에는 기능 상태와 작업 진입점만 남김. 화면 디자인/화면 분석 폼의 검증 설명과 실제 분석 결과는 해당 작업 화면에 유지(로그를 이중 노출하지 않음).

## 기록의 실제 출처
- **LOCAL**: SQLite `activity` 테이블에 저장된 메타데이터 (ID, 시각, 명령 종류, 처리 상태). 서버 API가 최근 최대 50개 반환.
- **SESSION**: 이 브라우저에서 발생한 로컬 연결 상태, 요청 응답 및 오류. 최대 160개까지 메모리에 유지. 페이지 새로고침 시 사라짐.
- 폴링은 페이지가 보일 때 15초 간격 및 명령 처리 직후. 서버 이벤트는 고유 ID로 중복 제거.
- 원문 음성, 명령 원문, 기억 본문, 스크린샷 이미지, 다른 Mac 앱의 로그는 수집하지 않음.
- 별도 서버 로그 수집기나 실제 셸이 아님. **자비스 앱의 통합 작업 기록 뷰어**.

## 사용법
1. 화면 오른쪽 `JARVIS CONSOLE`을 확인.
2. 작업 공간 열기/기억 조회/디자인 요청을 실행하면 실제 서버 이벤트와 UI 메시지가 기록됨.
3. `실행` 필터로 동작 이력, `오류` 필터로 경고와 구분된 오류만 보기.
4. `화면 지우기`는 **현재 보이는 세션 목록만 비움**. SQLite 서버 기록이나 저장된 기억은 삭제하지 않음.
5. 모바일에서는 아래쪽 `JARVIS CONSOLE` 헤더를 눌러 펼침/접기.

## 검증
- Python 단위 테스트: 활동 ID, 서버 API, 원문 명령·기억 비노출.
- JS 구문 검사: `terminal.js`, `app.js`.
- 실제 Chromium 데스크톱·모바일 UI: 패널 노출, 필터, 터미널 비우기 후 SQLite 보존, 중앙 활동 중복 제거, 가로 넘침 검사.
- 사용자 Mac 실기기와 연결된 외부 프로그램 로그는 아직 검증하지 못함.
