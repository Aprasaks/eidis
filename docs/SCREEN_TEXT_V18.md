# JARVIS 로컬 화면 글자 인식 v1.8

## 동작
- macOS 앱 **화면** 탭 → **화면 캡처 + 글자 읽기**를 사용자가 누른 경우에만 ScreenCaptureKit으로 디스플레이 한 장을 캡처합니다.
- JARVIS 앱 자신의 창은 캡처에서 제외합니다. 다른 창의 보이는 화면만 대상으로 삼습니다.
- 캡처 이미지로 Apple Vision `VNRecognizeTextRequest`를 실행하여 한국어와 영어 글자를 로컬에서 인식합니다.
- 이미지 미리보기와 인식된 글자를 앱에서 표시합니다. **글자 복사**는 별도 버튼을 눌렀을 때만 클립보드에 기록합니다.
- **지우기** 버튼을 누르면 앱의 캡처 이미지와 추출 글자를 메모리에서 해제합니다.

## 제한과 개인정보
- 자동 화면 캡처·상시 감시·외부 네트워크·AI API 호출·로컬 파일 저장·SQLite 기록은 하지 않습니다.
- 화면 인식은 OCR(문자 판독)일 뿐, 그림·그래프·버튼의 맥락을 해석하는 멀티모달 AI 분석 기능이 아닙니다.
- 비밀번호나 개인정보가 화면에 보이면 OCR 결과에도 포함될 수 있으므로 화면을 확인한 다음 사용하고, 복사한 내용의 보관에 유의하세요.
- macOS 화면 기록 권한은 사용자가 실제 앱에서 직접 승인해야 합니다. 권한 상태 조회만으로 실캡처 성공을 주장하지 않습니다.

## 검증
- Apple Vision이 한국어 `ko-KR`와 영어 `en-US` 인식을 제공하는 것을 사용자 Mac에서 확인.
- Mac SwiftUI 앱 실제 컴파일 성공.
- Mac에서 합성한 `JARVIS SCREEN TEST` 이미지에 대한 Vision OCR 실동작 테스트 통과.
- 화면 기록 권한과 실제 디스플레이 캡처 결과는 앱에서 직접 버튼을 눌러 확인해야 하며, 합성 이미지 검증은 이를 대신하지 않습니다.
