# STOCK BOARD 1.1 — 관심 종목, 차트, 시장 달력

- 관심 종목 최대 30개를 macOS UserDefaults에 별도 저장. 초기 목록은 빈 배열. 종목 코드 직접 입력, 알려진 한국어 별칭 음성 추가/제거/조회. 모든 임의 이름 검색은 아직 미지원.
- 토스 OpenAPI 명세 /api/v1/candles (1m, 1d; 최대 60개) 실제 응답에서 종가선과 마지막 봉 거래량을 표시한다. OHLC 촛대와 개별 시세 등락률은 별도 기능이다.
- /api/v1/market-calendar/KR, /US: 공급자가 반환한 날짜별 세션의 시작/종료 시각을 비교해 예정 시간대, 휴장일, 거래 예정 시간 외를 표시. 뉴욕 및 서울 날짜 기준, 이전 영업일의 자정 넘는 세션 포함. 공식 일정일 뿐 실제 거래소 운영 신호는 아님. 날짜 불일치 시 갱신 필요.
- API 조회 실패, 빈 목록, 시세 누락을 구분. 60초 자동 갱신은 선택형이고 보드가 열려 있는 동안만 동작. WebSocket 미구현. 실거래/계좌 접근 없음.
- Mac 전용 Toss Keychain 항목 등록이 확인되지 않아 실제 인증/시세 응답 미검증. 공식 JSON 예시 기반 테스트 25개와 기존 Python 회귀 287개 성공. 사용자의 마이크와 시각적 화면 검증 별도.
- 다음: 사용자 직접 자비스 전용 API 키 등록 → 실제 조회 검증 → 필요시 실제 시장 데이터 범위 조정 → Weather Center.
