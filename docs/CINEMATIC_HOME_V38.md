# JARVIS Mac v3.8 — Cinematic Home

## 핵심

기존 v3.7.1에서 이미 구현된 부팅 인트로, 동작하는 코어, 기억 및 작업 데이터 모델을 재사용했습니다. 이번 변경은 Mac 앱의 첫 화면을 중앙 코어 중심 시네마틱 홈으로 전환하고, 상세 대시보드로 언제든 다시 전환할 수 있도록 하는 실제 SwiftUI 화면 개선입니다.

- JARVIS.app 실행 → 기존 검증된 인트로 → 시네마틱 홈(기본값).
- 오른쪽 위 대시보드 버튼 → 상세 상태 화면. 상세 화면의 시네마틱 홈으로 돌아가기 버튼 → 시네마틱 홈.
- 사용자가 선택한 화면은 기기 내 AppStorage(JARVIS_CinematicHome_Enabled)에만 보관합니다. 프로젝트 작업 DB와는 별개입니다.
- 기존 웹 콘솔은 상세 대시보드에서 선택적으로 열 수 있습니다.

## 실제 화면 구성

- 중앙: 실제 네이티브 JarvisCoreView. SwiftUI 회전 링과 파형, macOS 동작 줄이기를 존중합니다.
- 왼쪽: 실제 로컬 서버 연결 상태, 사용자 기록 조회 결과, 한국어 음성 출력 지원, Apple 기기 내 모델 가용 상태.
- 오른쪽: 사용자가 저장한 다음 작업 제목과 프로젝트·작업 수. 확인되지 않은 상태는 미확인으로 표시합니다.
- 하단: 음성 탭, 작업, 수동 화면 캡처, 진단 바로가기. 음성 버튼은 마이크를 즉시 켜지 않고 음성 탭으로 이동합니다.

## 안전과 한계

실제 센서 분석, 음성 인식 또는 프로젝트 자동 완료를 가장하지 않습니다. 화면 개선은 SQLite, Git, AWS, 파일, 클립보드, 배포와 연결되지 않으며 새로운 외부 AI API를 호출하지 않습니다.

실제 사용자 프로젝트명이 포함된 앱 창은 Mac에서 별도로 확인했지만, 개인정보 보호를 위해 GitHub에 업로드하지 않았습니다. 공개 캡처는 모두 가상 프로젝트 데이터로 렌더링한 UI fixture입니다.

## 실제 검증, 2026-11-18 KST

- SwiftUI 전체 패키지 빌드 성공 및 Python 회귀/안전 테스트 134개 통과.
- 시네마틱 온라인·오프라인, 상세 대시보드, 실행 인트로 오프스크린 렌더링 성공.
- Mac JARVIS.app을 기존 3.7.1에서 3.8.0(빌드 39)으로 안전하게 교체하고 서명 확인.
- 설치 전 사용자 SQLite 백업 및 기존 설치 앱 백업.
- 실제 앱 창 확인, 로컬 서버 진단 HTTP 200, 프로젝트 2건 조회, SQLite quick_check=ok, 완료 14건/예정 11건 유지.
- 직접 GUI 버튼 클릭과 음성 실사용은 자동 UI 렌더링 검증과 별개이며 아직 완료됐다고 주장하지 않습니다.
- iPhone EIDIS 미변경, main 미병합.
