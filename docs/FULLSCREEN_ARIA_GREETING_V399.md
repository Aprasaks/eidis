# JARVIS v3.9.9 — 전체 화면 금빛 코어 + Aria 소환 인사

## 구현
- Cmd+Option+J 수동 소환으로 기존 1080p 원본 영상 그대로 전체 화면 코어 표시
- 이미 사용자가 활성화한 ElevenLabs 설정을 사용해 `네, 자비스입니다.` 인사 재생
- Apple Keychain 저장 API 키만 사용; 키·음성 데이터·개인정보 Git에 기록하지 않음
- 소환 인사는 **첫 한 번만** ElevenLabs 요청 (크레딧 사용 가능); 같은 실행 세션에서 반복 소환 시 메모리 캐시 재생
- 고른 Voice ID 또는 모델이 변경되면 캐시를 재사용하지 않음
- Escape 시 화면 즉시 닫기, 음성 플레이어 정지, 대기 중인 TTS 작업 취소, 응답이 늦게 와도 음성이 나오지 않도록 세대 토큰 검사
- macOS 오디오/명령 입력은 자동으로 시작하지 않음. 실제로 듣지 않는 상태에서 `듣고 있습니다`라고 주장하지 않도록 인사 문구 선정
- 메인 화면 추가 UI 없음, 영상 디자인 및 모니터 이동 유지

## 실제 기기 확인 (2026-11-20, Korea local time)
- 설치 `~/Applications/JARVIS.app` v3.9.9, codesign 검증
- Cmd+Option+J: 원본 금빛 코어 2560x1080 디스플레이에 표시 확인
- 첫 소환: 음성 탭 상태 `ElevenLabs 음성 재생 중 · 요청 1/5회`, 크레딧 사용 가능
- Esc 종료 후 다시 소환: `소환 인사 재생 중 · 저장된 오디오 재사용 (추가 크레딧 없음)`, 남은 요청 4/5 유지
- Esc 재종료: 오버레이 창 사라짐, 상태 `자비스 소환 음성 중단 · Esc`
- 로컬 진단 HTTP 200 및 기존 프로젝트 2개 유지
- Python 자동 테스트 147개 통과, Swift 빌드·서명 검증
