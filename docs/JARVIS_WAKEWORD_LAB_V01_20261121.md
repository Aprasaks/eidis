# JARVIS Wake Word Lab 0.1 — local feasibility
- Separate Python 3.10 venv: ~/.jarvis-lab/wakeword/venv (no production dependencies changed). openWakeWord 0.6.0, ONNX Runtime 1.23.2 arm64. Explicit ONNX official release assets from https://github.com/dscripka/openWakeWord/releases/tag/v0.5.1 (mel, embedding, hey_jarvis).
- Basic benchmark: 40 macOS TTS clips, all valid. At threshold .5, Korean 자비스/자비스? 0/8, 헤이 자비스 0/4, English Jarvis 2/4, Hey Jarvis 4/4. Silence peak .000045. Approx 118 s padded sample audio, 1.94 s inference; not real-time CPU/power measurement or actual speech accuracy.
- Custom prototype: streaming openWakeWord embeddings + logistic classifier exported ONNX, 52 synthetic clips, 1673 feature windows, holdout two named macOS voices not used for fitting, different rates, 8 positives and 56 negatives. At fixed .5, detections 5/8, false detections 3/56. LBFGS training emitted numerical warnings; prototype NOT approved for live always-on deployment. Model and synthetic results remain in ~/.jarvis-lab/wakeword, not bundled.
- START_JARVIS_WAKEWORD_TEST.command: explicit Enter, at most 45 s mic, scores and events only, no recording/file storage, no external speech transfer, no app actions. 16 kHz mono input format supported by PortAudio query, not actual microphone verification.
- START_JARVIS_WAKEWORD_ENROLL.command: optional user-controlled personal candidate training with separate spoken samples for validation. Raw samples held in RAM, not saved or sent. SAVE is explicit and requires 4/4 validation positives, 0/6 validation negatives. This small check does not certify reliable wake word or speaker identity. Candidate remains outside app.
- No background capture, launch agent, app integration, paid API, or ElevenLabs generation added. Existing JARVIS unchanged. Next: user's actual speech test; improve sample diversity and calibrate thresholds on development data; separate real quiet/noisy/TV/long negative test; only then consider opt-in voice integration with exclusive microphone ownership and speech output ducking.
- Model licenses and source training data terms must be checked for redistribution; no model binary in Git.
