# JARVIS v3.11.1 — 실제 웹페이지 읽기와 로컬 Qwen3.5 분석

## 이번 변경

- 기존 음성 명령 처리기(`JarvisCommandEngine`)에 허용된 `summarize_current_page` 도구를 추가했다.
- 사용자는 `이 페이지 요약해줘`, `지금 페이지 내용 분석해줘` 등 자연어 요청으로 현재 **JARVIS 내부 WebKit 브라우저에 열린 페이지**를 읽게 할 수 있다.
- 페이지는 `WKWebView.evaluateJavaScript`로 `article/main` 또는 `document.body.innerText`의 **보이는 텍스트만 최대 12,000자 읽기**. 쿠키·폼·HTML 원문·계정 데이터는 별도로 수집하지 않는다.
- 현재 열린 HTTPS 페이지, 페이지 로딩 완료, 최소 100자, 읽는 도중 페이지 이동 또는 창 종료 여부를 검증한다. 오류 시 결과를 지어내지 않고 사용자에게 다시 시도 안내.
- 추출한 텍스트 중 앞부분 최대 6,500자를 로컬 `qwen3.5:9b-q4_K_M`에 별도의 **도구 미제공(no tools)** 요약 요청으로 전달한다. 페이지 본문은 `<UNTRUSTED_PAGE_TEXT>`로 구분하고, 웹페이지 안의 지시는 절대 명령 실행으로 취급하지 않는다.
- 요약은 한국어로 짧게(최대 450자), 음성으로 안내. 왼쪽 패널에 요약문 전체를 **스크롤 가능**하게 표시하고 출처 제목과 호스트를 보인다. 오른쪽 원본 웹페이지는 열린 상태로 유지한다.
- 검색 결과 페이지를 요약하면 그 **검색 결과 목록**만 다뤘음을 명시하며, 개별 원문을 검증했다고 주장하지 않는다.
- 기존 금빛 코어, Aria 인사, 수동 소환, 음성 대화, 요청형 프로젝트 대시보드, 내부 웹 검색, `Esc` 전역 종료는 유지.

## 실제 맥 검증 (2026-11-20)

- JARVIS v3.11.0 실제 설치 앱에서 `Qwen3.5 공식 소개 검색해줘` 명령 → 자비스 내부 네이버 검색 페이지 로드.
- `지금 이 페이지 내용을 요약해 줘` → 본문 읽기, 별도 로컬 Qwen3.5 분석, 요약문 및 실제 `https://m.search.naver.com/...` 출처 표시 확인.
- 응답은 검색 목록/관련 발표를 요약했으며 개별 원문 확인이 아니라는 한계를 분명히 표현했다.
- 실제 2560×1080 전체 화면 스크린샷을 열어 금빛 코어, 오른쪽 웹 브라우저, 왼쪽 출처 표시 확인.
- 요약 자막이 길어져 말줄임표로 잘리는 부분을 개선해 스크롤할 수 있도록 한 최종 v3.11.1 Swift 빌드/계약 테스트 완료.
- 최종 v3.11.1 `~/Applications/JARVIS.app` 설치, 자동 테스트 164개 통과, macOS Apple Development 서명 검증.
- v3.10.9 → v3.11.0 → v3.11.1 업데이트에도 **SecurityAgent 키체인 허용 팝업 없음** 관찰. v3.11.1 코어 소환 직후에도 팝업 없음.
- `Esc`로 금빛 코어 즉시 종료 확인, 백그라운드 JARVIS 프로세스 유지, SQLite 진단 `ok`, 기존 프로젝트 2개/작업 25건 보존.
- 이전 설치 앱 별도 백업: `~/Applications/JARVIS-Backups/JARVIS-before-v3111-20261120.app`.

## 범위와 한계

- 현재 **한 번에 한 웹페이지의 표시된 텍스트를 분석**한다. 검색 결과를 모두 열어 사실 대조하는 자동 다중 출처 조사 기능은 아직 아니다.
- 영상/음성/이미지 자체를 이해하지 않는다. YouTube 자막 분석, GitHub 저장소 탐색, Notion/Obsidian 편집, 사진 정리는 별도 실행기 필요.
- 사이트별 JavaScript 로딩·로그인·자동화 제한으로 본문 추출 실패할 수 있다. 불러온 결과의 정확성은 사용자 검증이 필요하다.
- Qwen 텍스트 분석 자체에는 별도 외부 AI API 사용료 없음. 다만 **원문 페이지 방문은 외부 서버와 통신**하며, Aria가 결과를 읽을 때 그 텍스트는 ElevenLabs TTS로 전송되고 계정 크레딧이 사용될 수 있다.
- 웹 콘텐츠가 실행 명령으로 흐르지 않도록 요약용 모델 요청에 tools를 제공하지 않는다. 저신뢰 문서/프롬프트 인젝션을 완벽히 걸러낸다는 뜻은 아님.
- Apple Development 서명을 일정하게 유지하는 이전 v3.10.9 개선을 그대로 보존. macOS의 키체인 ACL/서명 정책 또는 인증서 교체 시 허용 창이 다시 뜰 가능성까지 배제하는 건 아님.
