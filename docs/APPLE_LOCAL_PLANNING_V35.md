# JARVIS v3.5 — Mac 기기 내 AI로 다음 행동 제안

## 변경점

저장된 프로젝트, 마지막 수동 Git 상태, 승인해 확인한 마지막 GitHub 기록, 그리고 사용자가 직접 읽어 둔 동일 작업의 메모 일부를 바탕으로 Apple Foundation Models가 다음 확인 행동을 제안합니다.

- Mac 작업 탭에서 프로젝트 선택 → Mac 기기 내 AI → AI로 제안받기를 누릅니다.
- 대상 작업 ID는 저장된 진행 중 작업 우선, 다음으로 예정 작업입니다. 모델이 임의로 다른 작업 ID를 선택하지 못합니다.
- 출력은 첫 확인 / 그 이유 / 검증 방법 형식의 기기 내 모델 답변입니다. 사용자 기록과 비교해야 합니다.
- 모델이 비활성/미설치이면 에러를 보여 주고 외부 AI API로 자동 연결하지 않습니다.
- Apple 기기 내 모델만 사용. OpenAI API 결제나 별도 키가 필요하지 않습니다.
- 프로젝트 선택을 바꾸거나 해당 작업 ID·제목·상태가 바뀌면 생성된 제안을 사용하지 않습니다.
- 생성 결과는 화면 메모리에만 유지. 사용자가 복사 버튼을 누를 때만 클립보드에 복사합니다.

## 데이터 경계

- 작업명, 목표, 상태는 사용자 입력이지 현재 코드 실행의 증거가 아닙니다.
- 로컬 Git은 마지막 명시적 수동 조회의 시각·브랜치·HEAD·변경 건수만 사용하며 Mac 폴더의 절대 경로는 제외합니다.
- 공개 GitHub 상태도 마지막 승인 조회 기록만 활용하며 새로운 웹 요청을 하지 않습니다.
- 실행 메모는 해당 프로젝트의 **같은 작업 메모를 사용자가 직접 열어 두었을 때만** 최대 1,400자를 사용합니다. 별도의 프로젝트 파일을 자동 검색하지 않습니다.
- 외부 API 호출, 코딩, 파일 수정, Git push, 명령 실행, 배포, DB 상태 변경, 브라우저 열기 등은 전부 수행하지 않습니다.
- Apple Foundation Models의 언어 생성은 부정확할 수 있습니다. 계획은 제안이며, 테스트·배포·작업 완료 사실로 간주하지 않습니다.

## 기술/검증

- Apple M4 Pro/macOS 26.5.1 환경에서 SystemLanguageModel.default.availability가 available임을 확인했습니다.
- 가상 테스트 프로젝트에서 LanguageModelSession을 통해 실제 한국어 답변 생성 성공.
- Swift fixture: 고정된 작업 ID, 문서/스냅샷 범위, 다른 프로젝트의 메모 미혼입, 개인 경로 미노출, 기록 상태 변경 시 무효화.
- macOS 26 미만 또는 시스템 모델 미지원 환경은 기능 비활성으로 안내.
- 실제 사용자의 Mac 앱 UI 클릭·실제 사용자 프로젝트 AI 제안은 자동 테스트와 별도의 실사용 검증 대상입니다.
