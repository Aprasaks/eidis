# JARVIS v3.3 — 로컬 텍스트 명령 실제 왕복 점검

## 목적
Mac 앱의 서버 연결 상태와 자비스의 프로젝트 기록 응답을 **실제 명령 한 번**으로 검사합니다. 이전 진단은 대부분 권한·서버 상태만 조회했으므로, 이 검사는 명령을 보냈을 때 돌아오는 값까지 확인합니다.

## 실행 방법
1. Mac에서 JARVIS를 엽니다.
2. **진단 → 로컬 텍스트 명령 왕복 점검**을 클릭합니다.
3. 표시된 시각과 **성공/실패** 설명을 확인합니다. **결과 복사**로 증거를 보관할 수 있습니다.
4. 음성 자체는 별도입니다. 실제 발화 확인은 **음성 → 마이크로 말하기 → 완료하고 명령 전달**을 직접 시험해야 합니다.

## 검증하는 것
- 사용자 Mac의 **127.0.0.1:8765** 로컬 서버에 연결하여 등록된 프로젝트 목록을 조회합니다.
- `JARVIS eidis` 및 `Aprasaks/eidis`로 등록된 정확한 프로젝트가 하나인지 확인합니다.
- `자비스, 다음 할 일 뭐야?`라는 **텍스트 명령**을 로컬 `/api/chat`로 한 번 전송합니다.
- 응답이 `project_self_overview`, `executed=false`, `brain_source=local`이며 자비스 자신의 프로젝트 기록이라는 내용인지 확인합니다.
- 이 조건이 모두 맞는 경우에만 성공을 표시합니다. 저장된 작업의 시작/완료 상태를 변경하지 않으며 `remote_consent=false`로 외부 AI 동의를 주지 않습니다.

## 검증하지 않는 것
- 마이크 음향 입력·한국어 실제 전사·TTS 음성 재생
- Finder 또는 GitHub 화면의 실제 열림, UI 버튼의 OS 외부 자동 클릭
- 화면 캡처와 macOS 권한 요청 성공
- GitHub 최신 상태, 프로젝트 배포 완료 여부
- 터미널에서 같은 점검 코드를 실행한 결과가 **앱 내부 버튼 클릭 성공**을 의미하는 것은 아닙니다.

## 안전 기준
로컬 프로젝트 목록 GET과 로컬 채팅 POST만 수행합니다. 외부 GitHub/AI 호출, 코드 수정, 프로젝트 태스크 상태 변경, 파일 생성, 배포는 없습니다. 로컬 채팅 서버는 테스트 명령을 일시적 대화 맥락에 남길 수 있지만, 기능 자체는 자동 명령 실행을 요청하지 않습니다. 음성 인식 권한 요청은 이 버튼에서 발생하지 않습니다.

## 검증 기록
Mac의 터미널에서 **동일한 Swift 왕복 점검 모듈**을 실행해 실행 중인 서버가 예상한 응답을 반환한 것을 직접 확인했습니다. 실제 앱 버튼 클릭은 사용자 실사용 확인이 남아 있습니다.
