# WEATHER CENTER 1.0

- "자비스, 오늘 날씨 알려줘", "군산 날씨 어때", "내일 서울 날씨 알려줘", "날씨 새로고침", "날씨 화면 닫아" 명령. 작은 코어에서 기존 전체 작업 화면 전환, 오른쪽 전용 날씨 보드. 뉴스/주식/브라우저/다른 보드를 열면 날씨 닫힘.
- Open-Meteo Forecast API(https://open-meteo.com/en/docs). 무료 개인 비상업 사용, 출처 표시 CC BY 4.0. 별도 유료 API나 새 인증 필요 없음. 상업 운영 전 이용 조건 재검토.
- 군산 기본, 10개 국내 도시 중심의 사전 정의 좌표 사용. UI 기본 지역 저장 가능. 위치 센서/정확한 사용자 위치/사용자 음성 원문 전송 없음. 미지원 지역은 추측 조회하지 않음.
- 현재 모델 추정 기온, 체감, 습도, 풍속, 앞으로 최대 24시간 예보, 7일 최저/최고 기온·최대 강수확률. 현재값은 관측 실측값이 아님. KST의 자료 기준 시각 및 조회 시각 표시. null은 미확인으로 표시. 실제 기상특보와 미세먼지는 범위 밖.
- 고정 HTTPS 호스트, 리다이렉트 금지, 요청 제한 시간, 응답 검증. 명시 요청 시 수집, 도시별 10분 캐시(KST 자정 이후 재조회), 수동 새로고침. 실패 시 현재 도시의 이전 자료라는 표시, 자동 상시 수집 없음.
- 검증: Swift 예제/명령 테스트 15개, 실제 Swift API 호출로 군산 및 서울 24시간/7일 응답 확인(2개 총 약 1.37초, 당시 시험 값). 마이크 실제 인식 및 실기기 UI 확인은 사용자 별도.
