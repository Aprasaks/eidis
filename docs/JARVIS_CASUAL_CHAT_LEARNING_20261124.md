# JARVIS 일상 채팅 · 기억 학습 연결 (Mac v3.14.15)

## 목표
오라버니가 자연스럽게 Mac 자비스와 **문자로 대화**하고, 동의한 경우에만 일상 대화에서 유용한 취향·소통 방식·작업 원칙 등을 Qwen3.5가 **기억 후보로 학습**하도록 한다. 단순 대화를 업무 실행 명령으로 오인하는 문제를 피한다.

## 이용 방법
1. Mac에서 `JARVIS.app` 실행 → 전체화면 자비스 열기.
2. 화면 하단에 항상 보이는 **일상 채팅** 버튼을 누른다. 또는 “자비스, 채팅하자”, “일상 채팅 시작해”.
3. 채팅 화면에서 평범한 이야기를 입력하고 Enter 또는 전송 버튼을 누른다.
   - 예: “오늘은 그냥 쉬고 싶어”, “요즘 과학책 읽는 게 좋아”, “이번 주는 정신없이 바빴네.”
   - 이 모드에서 Qwen은 도구·파일·계정 조작을 하지 않으며 대화 자체에 응답한다.
   - 입력 대답은 텍스트로 표시하고, 문자로 보낸 메시지는 자동 TTS 낭독을 하지 않는다. 마이크 입력은 기존 음성 답변 경로 유지.
4. **기억 설정**을 눌러 로컬 대화 학습을 켠다. 이전처럼 기본값은 꺼짐이다.
5. 일정한 선호·취향·작업 원칙 등이 발언되면 Qwen이 비동기로 짧은 **기억 후보**만 추출한다. 승인 전에는 답변에 반영되지 않는다.
6. 화면의 **기억 후보 검토**에서 승인 또는 거절한다. 승인된 기억은 다음 대화와 재실행 뒤에도 참고한다.
7. **채팅 닫기**를 누르면 기존 대시보드·명령 중심 UI로 돌아간다.

## 기술적인 경계
- 채팅은 로컬 Ollama `qwen3.5:9b-q4_K_M`로 스트리밍 응답한다.
- 최근 대화 8개 메시지는 프로세스 메모리(RAM)에만 보관하여 이어 말하기에 사용한다.
- 영구 기억은 `~/.jarvis-lab/memory.sqlite3`의 `learned_memories` 등에 후보 및 승인 기록을 저장한다.
- 기억 후보 추출은 **답변 이후**, 옵트인 상태에서만 실행한다. 마이크 녹음이나 전체 대화록을 영구 저장하지 않는다.
- 빠르게 이어지는 대화로 추출이 중단되어도 최대 8개 사용자 발언을 RAM 임시 대기열에 남겨, 다음 정상 응답 후 다시 추출을 시도한다. 앱을 닫으면 미처리 대기열은 사라진다.
- 현재 구조는 **Qwen 모델 가중치를 재학습시키는 것이 아니다.** 검색 가능한 기억 축적이다. iPhone 동기화는 이번 변경 범위가 아니다.
- 자연스러운 발언에서 기억 후보를 제안하더라도 오류 가능성이 있으므로 **사용자가 승인하기 전에는 사실이 아니다.**
- 비밀번호·토큰·일부 연락처 등 민감정보 차단이 있지만 모든 비밀을 자동 탐지할 수는 없다. 민감한 대화에서는 학습을 끄고, 후보를 검토한다.
