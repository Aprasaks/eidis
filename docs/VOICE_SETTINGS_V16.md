# JARVIS macOS 목소리 설정

## 이번 변경
- macOS 앱의 **음성** 탭에 `자비스 목소리` 설정을 추가합니다.
- Mac에 설치된 한국어(`ko-KR`) 시스템 음성을 목록에서 선택할 수 있습니다. 설치된 음성만 표시합니다.
- `미리 듣기` 버튼으로 자비스의 짧은 한국어 응답을 직접 들어봅니다.
- 말하는 속도(0.38~0.58), 음높이(0.75~1.25)를 조절하고 `초기화`로 기본값을 되돌릴 수 있습니다.
- 초기값은 사용 가능한 경우 **Reed**, 속도 0.45, 음높이 0.88입니다. 음성 이름/음질은 각 Mac에서 다를 수 있습니다.
- 선택값은 macOS UserDefaults에 저장해 앱을 다시 열어도 유지됩니다.
- 자비스 기본 탭의 음성 미리 듣기와, **음성 탭의 실제 명령 결과를 읽어주는 응답**이 같은 설정을 사용합니다.
- macOS 내장 AVSpeechSynthesizer만 사용합니다. 유료 TTS API, 오디오 파일 업로드, 새 녹음, 서버 변경 없음.

## 실제 Mac 사용 방법
1. 최신 `eidis` 코드를 사용한 JARVIS.app을 실행합니다.
2. 상단 **음성** 탭으로 이동합니다.
3. `목소리`에서 Reed / Eddy / Flo / Yuna 등 **Mac에 실제 설치된 음성**을 선택합니다.
4. `미리 듣기`를 누르고, 속도/음높이를 조정해 다시 들어봅니다.
5. '자비스'라고 말하고 명령을 전달하면 방금 선택한 목소리로 답변합니다.

## 검증/제약
- SwiftUI 앱 빌드와 소스 계약 테스트로 동일한 음성 서비스 사용 및 선택 항목 존재 여부를 검사합니다.
- 실제 발화가 자연스럽게 들리는지는 사용자 Mac 스피커에서 직접 비교해야 합니다.
- 한국어 온디바이스 음성 **입력** 인식과 TTS **출력**은 별개 기능이며, 이번 변경은 출력 음성에만 적용됩니다.
- 고품질 음성 엔진·감정 표현·웨이크워드·연속 대화는 이번 변경 대상이 아닙니다.
