# JARVIS v3.10.4 — ElevenLabs 횟수 제한 제거 + 요청형 로컬 작업 대시보드

## 변경 사항

1. ElevenLabs TTS **앱 내부의 5회/실행 제한 제거**. 사용자 설정(`enabled`)과 Mac Keychain 저장 API 키 사용 방식, 중복 생성 차단, 긴 문장 600자 보호, Esc 취소, 서비스 제공자의 크레딧 및 402/429 응답 처리 모두 유지. `attempts`는 사용 횟수 표시에만 활용. 별도 API 사용 요금은 발생할 수 있음.
2. 기존 `127.0.0.1:8765/api/projects`의 JSON을 **GET으로만** 읽어 사용자가 기록한 실제 프로젝트와 작업 상태 표시. 프로젝트 및 작업 값 임의 생성 없음. 이 GET은 DB를 수정하지 않음.
3. 명시적인 한국어 명령 `작업 보여줘`, `프로젝트 현황`, `대시보드 띄워줘` 등만 대시보드를 열고, `대시보드 닫아`, `작업 숨겨줘` 등은 패널만 숨김. 그 외 질문은 기존 Qwen3.5 로컬 AI로 처리.
4. `JarvisOverlayDashboard`가 세션당 새로 조회하고, 오류 시 오래된 데이터를 현재 상태처럼 표시하지 않으며, Esc 시 요청 취소 및 세션 파기.
5. 금빛 원본 영상 `JARVIS_FullHD_Loop.mp4` 무변경. 대시보드는 오른쪽에만, 질의응답 자막은 왼쪽 하단에 표시해 원본 코어와 `JARVIS` 로고가 가리지 않도록 배치.
6. 기존 Aria 인사와 대화 흐름, Mac 한국어 인식, Qwen3.5, Cmd+Option+J, Esc, 모니터 이동 유지. 프로젝트 상태 수정·GitHub 호출·배포·파일 조작은 없음.

## 아직 제공하지 않는 범위

- 대시보드는 현재 **JARVIS가 이미 저장한 프로젝트/작업 기록**만 조회. 외부 일정, 날씨, 실시간 시스템 수치, GitHub 상태, 화면 분석 등은 자동 연결하지 않음.
- 실제 구두 명령 인식 문구는 환경·발음에 따라 달라질 수 있음. 음성 인식 단계 이후의 명령 처리 코드 경로는 텍스트 입력과 동일하지만, 사용자 목소리로 대시보드 명령 전체를 완료하는 최종 청취 테스트는 사용자가 진행해야 함.
- 횟수 제한 제거는 공급자 ElevenLabs의 구독 한도/계정 크레딧을 우회하지 않음. 비용을 예상할 때는 ElevenLabs 계정의 크레딧 사용량 한도 확인 권장.
- 자동화·백그라운드 예약·미승인 파일 수정 기능은 없음.
