# JARVIS MINI CORE 2.0 — 가벼운 상시 대화 모드
2026-11-21

## 변경
- 기존 Command+Option+J 전체화면 단축키 유지. 새 Command+Option+S 전역 단축키로 작은 코어 표시/숨김. 전체화면 중에는 작은 코어 복귀 설정을 전환한다.
- 검정 사각형 프레임 제거, 원본 영상을 원형으로 마스킹. 원본 MP4 자체의 검은 픽셀을 투명화한 것은 아니다.
- 드래그 전용 손잡이, +/- 크기 조절(160~340pt), 닫기 버튼. 위치·크기는 UserDefaults에 보존하며 모니터 변경 시 화면 안으로 보정한다.
- 작은 창의 마이크 버튼 또는 Option+Space로 기존 음성 대화 시작/종료. 질문 한 번이 끝나면 자동 재청취하지 않는다. 아무 말도 없는 30초 또는 120초 연속 캡처에 상한을 적용한다. 상시 핫워드 감지나 숨겨진 녹음 없음.
- 음성 인식·응답 작성·재생 중 표시되는 임시 자막과 오류 안내. 정상 대기 때 자막 영역 축소. 답변 실시간 텍스트와 원래 음성 엔진 재사용.
- 실제 브라우저/대시보드/자료실 실행 경로에서 동일 대화 인스턴스를 전체화면으로 넘긴다. 작은 영상 플레이어 해제 후 전체화면이 열리며 새 인사로 진행 중인 응답을 끊지 않는다.
- 작은 모드 대화 중 기존 백그라운드 추론을 양보시키며 음성 한 턴 종료/창 닫기 후 복귀한다.
- API 연동, 개인 DB, 모델과 금빛 코어 영상 변경 없음.

## 검증 범위
- Swift 빌드, Python 회귀 테스트 281개, Mac Carbon 단축키 등록 시험.
- 실제 사용자 키 입력, 마이크 인식, 코어 이동/크기 조절, 전체화면 자동 확장과 시각적 자막은 사용자 환경에서 추가 확인 필요. 전체 음성 왕복 시험 완료로 표시하지 않는다.
