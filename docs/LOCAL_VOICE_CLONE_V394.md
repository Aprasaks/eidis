# JARVIS v3.9.4 — 로컬 내 목소리 복제 (시험)

## 이번 작업에서 확인된 것

- Apple M4 Pro / 24 GB Mac에서 독립 Python 3.13 가상환경에 `mlx-audio==0.6.3` 설치
- Qwen3-TTS Base 모델 `mlx-community/Qwen3-TTS-12Hz-0.6B-Base-bf16` 다운로드
- 마이크를 사용하지 않은 **macOS 기본 합성 음성**으로 로컬 기능 테스트: 한국어 새 문장을 약 4.6초 WAV로 생성
- 모델 다운로드를 완료한 뒤 `HF_HUB_OFFLINE=1` 상태에서 다시 로컬 합성 성공
- SwiftUI `내 목소리 설정` 화면을 JARVIS 메뉴 막대에 추가하고 실기기 실행 확인
- 사용자의 기존 JARVIS 앱은 백업한 뒤 v3.9.4 설치. 프로젝트 기록은 유지

## 사용자 동작이 필요한 부분

1. Mac 상단 메뉴 막대의 JARVIS 아이콘 → **내 목소리 설정**을 선택한다.
2. 표시된 문장을 자연스럽고 차분하게 읽으며 **내 목소리 녹음**을 누르고 10~20초 후 **녹음 끝내기**를 누른다.
3. **녹음 듣기**로 본인 목소리가 맞는지 확인한다.
4. **내 목소리로 자비스 시험 음성 만들기** → **생성 음성 듣기** / **낮은 톤 듣기**를 비교한다.
5. 모델이 자신의 목소리와 비슷하게 나오는지 사용자가 직접 확인한다.

기존 파일을 선택할 수도 있지만 이 경우에는 실제 녹음 내용과 정확히 일치하는 `참조 음성 텍스트`를 반드시 입력한다.

## 파일과 프라이버시

- 실행 환경: `~/Documents/JARVIS-VOICE-LOCAL/.venv`
- 원격에 공개 가능한 **코드 원본**: `tools/local_voice/generate_clone.py`
- 실행 코드 복사본: `~/Documents/JARVIS-VOICE-LOCAL/generate_clone.py`
- 사용자 녹음과 출력 경로: `~/Library/Application Support/DECHIVE-JARVIS/voice-clone/`
- **녹음 음성은 Git에 저장하지 않는다.** 별도 명시적인 녹음/합성 버튼을 누를 때만 작동한다.
- MLX 모델 가중치 최초 다운로드는 외부 서버를 사용하지만 사용자의 녹음 파일은 전송하지 않는다. 실제 생성 subprocess에서는 `HF_HUB_OFFLINE=1` 설정을 사용한다.
- 필요하다면 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 JARVIS 권한을 허용한다.

## 아직 미검증/미구현

- **실제 사용자 목소리로 생성 테스트**: 사용자 녹음이 아직 없어 검증하지 못함
- **라이브 JARVIS 응답에 사용**: 아직 변경하지 않았음. 현재는 새 파일을 만들어 비교 청취하는 준비 단계
- 목소리 유사도, 낮은 톤의 자연스러움, 실제 응답 지연: 사용자 음성을 확보한 후 검증 필요

## 보존

기존 애플리케이션, ElevenLabs 설정, 데이터베이스 및 전체 화면 애니메이션은 변경하지 않는다. 전체 화면 코어는 ⌘⌥J로 실행한다.
