# JARVIS native SNS dashboards — 2026-11-22

SNS 카드 및 기존 SNS 열기 음성 명령은 이제 Chrome 창 배치가 아니라 JARVIS 고유의 검정·amber 대시보드를 연다. 왼쪽의 실제 코어와 대화 객체는 유지한다. Chrome 세션 확인 및 기존 외부 브라우저 코드는 별도 보조 기능이며 자동 호출하지 않는다.

- Instagram: 검증된 계정의 프로필, 팔로워, 게시물 수, 최근 최대 8개 게시물의 이미지/텍스트/시각/제공되는 반응 수. 실제 게시물 1개 및 이미지 렌더 확인.
- Facebook/Threads: 검증된 토큰의 전용 계정 조회 및 최근 게시물 GET 경로를 구현. 실계정 게시물 조회는 별도 현장 확인 필요. API 실패/미제공 수치는 0으로 대체하지 않는다.
- YouTube: 기존 읽기 전용 OAuth 연결, uploads playlist의 최근 최대 8개 영상, 썸네일, 업로드 시각. 구독자/영상/조회수 및 기존 기간별 분석 지표. 실제 API 8개 반환과 네이티브 화면 렌더 확인.
- 화면은 읽기 전용이며 게시, 댓글 작성, 광고 집행은 수행하지 않는다. 인증 정보는 기존 Keychain 경로를 사용한다. Chrome 쿠키 이동 없음.
- 테스트: Swift 빌드, 기존 Python 325개, 앱 서명, 설치, 실제 Instagram/YouTube 화면 확인, Instagram에서 전체 관제실 복귀 확인. 실제 음성 발화 검증은 남아 있다.
