# EIDIS iPhone 0.4 — 무료 기능 연결

2026-11-17, 기존 EIDIS 0.3을 삭제하지 않고 실제 iPhone 13에 **EIDIS 0.4 (빌드 4)** 업데이트 및 앱 실행까지 확인했습니다. 기존 Mac JARVIS 서버 및 작업 기록은 건드리지 않았습니다.

## 구현된 기능

- **“애기야” 호출어**: 가운데 마이크를 누르고 발화하면 기기 내 한국어 인식에서 “애기야”, “아기야”, “애기”를 힌트로 사용합니다. “애기야 날씨”, “애기야 오늘 일정”, “애기야 할 일”을 각각 다른 기능으로 처리합니다. **앱 밖에서 항상 듣는 웨이크워드는 아닙니다.**
- **실제로 회전하는 코어**: SwiftUI로 각기 다른 속도로 회전하는 링과 빛을 그립니다. 듣는 동안 변화하며 iOS 동작 줄이기와 백그라운드 전환을 따릅니다. GIF나 녹화영상이 아닙니다.
- **iPhone 캘린더**: 다음 일정 카드를 누르고 연결을 승인하면 Apple 캘린더의 향후 7일 이벤트를 읽어 표시하고 음성으로 답합니다. 읽기에도 iOS 전체 접근 승인이 필요하지만 앱은 일정을 변경하지 않습니다.
- **iPhone 미리 알림**: 오늘의 작업 카드를 누르고 연결을 승인하면 실제 미완료 항목을 읽어 표시하고 음성으로 답합니다. Mac JARVIS의 프로젝트 작업과는 별도입니다.
- **날씨**: 날씨 카드를 누르고 위치 권한을 허용하면 Open-Meteo의 현재 기온·체감 기온·습도·풍속·기상 상태를 가져옵니다. 사용자가 누른 순간에만 위치 좌표를 Open-Meteo에 전송하며, 대화·일정·작업은 전송하지 않습니다. 정보 만료와 오류를 구분합니다.

## 한계·비용·개인정보

- OpenAI API 크레딧 없이 작동하도록 개발했습니다.
- 날씨는 Open-Meteo 개인 비상업적 무료 API(키 필요 없음) 사용. 출처: Open-Meteo, CC BY 4.0. 상업적 이용 시 라이선스를 별도로 확인해야 합니다.
- 범용 개인 AI 모델, 실시간 카메라 사물 분석, Mac 프로젝트 기록 동기화, 길 안내, 앱을 닫은 상태에서 항상 듣는 호출어는 **미구현**입니다.
- 날씨 요청은 Mac에서 외부 API를 직접 시험했으나 타임아웃이 발생하여 **실제 날씨 정보 수신은 아직 검증되지 않았습니다**. iPhone에서 조회 성공을 확인해야 합니다.
- 캘린더·미리 알림 개인 데이터는 사용자가 권한을 승인하기 전까지 읽을 수 없습니다. 실제 항목을 불러왔다고 표시하지 않습니다.

## iPhone에서 확인할 일

1. **현재 날씨** 카드 → 위치 허용하고 날씨 조회 → 허용 → 실제 날씨 또는 오류 문구 확인.
2. **다음 일정** 카드 → 캘린더 연결 → iOS 접근 승인 → 실제 일정 목록 확인.
3. 화면을 조금 내려서 **오늘의 작업 · 미리 알림** 카드 → 연결 → iOS 접근 승인 → 미완료 목록 확인.
4. 가운데 마이크 → “애기야, 오늘 일정 뭐야” → 다시 눌러 종료 → 실제 일정에 근거한 음성 답변 확인. 텍스트 입력도 지원합니다.

권한을 거절했다면 각 연결 화면에 있는 iPhone 설정 열기를 이용해 변경할 수 있습니다.

## 직접 확인한 결과 (2026-11-17 KST)

- Python 회귀 테스트 129개 통과, 별도 Swift 한국어 명령 분류 테스트 통과.
- iPhone 13 시뮬레이터 빌드·설치·실행·실제 UI 캡처 성공: [EIDIS 0.4 실제 시뮬레이터 화면](../screenshots/EIDIS_v04_iPhone13_simulator.png).
- 실물 iPhoneOS 서명 빌드 및 코드 서명 검증 성공. 새 위치·캘린더·미리 알림 권한 설명도 빌드된 Info.plist에서 검증했습니다.
- 실물 iPhone 13에서 기존 EIDIS 0.3을 삭제하지 않고 0.4로 업데이트 설치, 앱 실행 및 프로세스 유지 확인.
- 실제 iPhone에서 새 데이터 연동 권한 승인과 해당 기능을 직접 눌러 확인하는 실사용 검증은 남아 있습니다.
- 별도 Git worktree에서 작업하여 원래 Mac JARVIS 작업 파일과 Xcode 개인 개발팀 설정을 보존했습니다.
