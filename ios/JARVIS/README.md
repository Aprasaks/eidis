# JARVIS iPhone 0.2 — Cinematic HUD

실제로 iPhone에서 실행되는 JARVIS의 두 번째 버전입니다. 사용자가 승인한 미래형 시안을 바탕으로 화면을 재설계했습니다. 기존 카메라·한국어 음성 입력·기기 내 음성 출력·직접 입력 기능을 유지합니다.

## 새로운 화면 구성

- JARVIS 헤더와 기기 상태, 단정한 다크 네이비·시안 HUD
- 실시간 후면 카메라 위의 얇은 스캔 프레임. 카메라 OFF 시에는 HUD PREVIEW 도시 일러스트로 구분
- 반투명 유리형 날씨·일정 카드. 실제 연결 전이므로 수치나 가짜 시간은 표시하지 않음
- 인식된 질문과 자비스 응답 카드. 터치하면 문장 전체와 응답을 확인 가능
- 중앙의 큰 원형 음성 버튼, 좌측 문자 입력, 우측 카메라 ON/OFF
- 우측 상단 상태 버튼: 지원하는 기능과 아직 미연결 기능을 분리 표시
- 앱이 백그라운드로 이동하면 카메라와 마이크를 멈춤

## 실제 기능

- 카메라: 사용자가 버튼을 누르고 허용한 뒤 iPhone 후면 미리보기 표시
- 음성: 사용자가 직접 버튼을 누를 때만 한국어 기기 내 인식 후 답변을 한국어로 읽음
- 문자: 키보드 시트에서 직접 질문할 수 있음
- 응답: 현재 규칙 기반 로컬 응답. 개인 AI, Mac 기억, 인터넷, 날씨·일정, 지도 및 물체 인식은 연결되지 않음
- 개인 사진/마이크 데이터는 서버에 전송하지 않음

## 개발·검증 기록 (2026-11-16)

- 새 시네마틱 화면을 iPhone 17 Pro / iPhone 13 시뮬레이터에서 각각 빌드·실행하고 실제 렌더링 화면을 확인함
- 전체 Python 계약/안전 회귀 테스트 128개 통과
- 이전 JARVIS 0.1은 실물 iPhone 13에 실제로 설치·실행되고, 사용자가 카메라/한국어 음성 인식/소리 출력 성공을 직접 확인함
- **JARVIS 0.2의 서명 빌드·업데이트 설치·기기 프로세스 실행이 실제 iPhone 13에서 확인됨.** 기존 0.1을 삭제하지 않고 같은 앱 ID로 업데이트했고, iPhone의 설치 목록에 0.2 (빌드 2)가 표시됨
- 단, 0.2의 새 화면에서 카메라·마이크를 사용자가 직접 눌러보는 실사용 검증은 별도

## Xcode

Mac에서 ios/JARVIS.xcodeproj를 열고 JARVIS 스킴을 고릅니다. 실기기 배포 시 본인의 Development Team과 Automatically manage signing을 사용합니다. 코드가 보관되는 공개 브랜치에는 로컬 Apple 계정 자격 증명을 넣지 않습니다.

JARVIS 0.2는 같은 설치 식별자 dev.dechive.jarvis.ios를 사용하므로 정상적인 iOS 업데이트 설치 시 0.1 앱을 삭제하지 않고 교체합니다. 앱을 삭제하거나 사용자 데이터를 초기화하는 스크립트는 사용하지 않습니다.
