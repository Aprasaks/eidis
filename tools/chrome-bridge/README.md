# JARVIS Chrome 연결 (선택적 / 읽기 전용)

Chrome 144+의 공식 Chrome DevTools MCP `--autoConnect`로 **현재 사용자의 Chrome** 연결 승인 여부만 확인하는 보조 도구입니다. 비밀번호·쿠키·로컬 저장소·웹페이지 텍스트는 읽거나 반환하지 않습니다. 앱은 승인된 DECHIVE 계정 URL이 열려 있는지에 관한 최소 정보만 받습니다.

## 1회 설정

1. Chrome에서 `chrome://inspect/#remote-debugging`을 열고 Remote Debugging을 사용자가 직접 켭니다.
2. JARVIS Meta 카드의 **Chrome 세션 확인** 버튼을 누릅니다.
3. Chrome이 디버깅 허용을 요청하면 사용자가 직접 `Allow`를 누릅니다. 거부하면 연결하지 않습니다.

이 기능은 기본 비활성이고 버튼을 눌렀을 때만 실행합니다. Chrome은 원래 권한 있는 세션 전체의 사이트에 접근할 수 있는 기술이므로, 신뢰할 수 없는 에이전트나 원격 시스템에 직접 연결하지 마세요. 자비스 어댑터는 `list_pages` 하나만 사용하고, DECHIVE 프로필의 존재 여부 외에 어떤 탭 정보도 공개하지 않습니다. 다른 탭은 조작하지 않습니다. 본격적인 페이지 읽기·업로드·게시·삭제는 이 버전에 포함하지 않았습니다.

## 실행/개발

`npm ci --ignore-scripts` 이후 `node check.mjs` (원격 디버깅이 켜져 있어야 하고 Chrome 동의가 필요). 앱 빌드 시 이 폴더의 스크립트 및 설치한 의존성만 서명하여 번들에 넣습니다. API 토큰/브라우저 프로필 자체는 복사하지 않습니다.
