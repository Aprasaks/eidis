# EIDIS / JARVIS macOS Native Lab (v0.2)

이 폴더는 다음 단계의 **실제 SwiftUI 네이티브 셸과 ScreenCaptureKit 화면 캡처 테스트**입니다. 여전히 완성된 개인 AI가 아닙니다.

## 요구 환경

- macOS 14 이상
- Xcode 및 Xcode Command Line Tools (Swift 5.9+)
- Python 3 (기존 로컬 서버를 실행할 때만)

## 실행

터미널 창 1: 저장소 루트에서 `python3 app.py`

터미널 창 2: 저장소 루트에서 `swift run --package-path macos`

첫 탭은 기존 브라우저 기반 UI를 Mac 창 안에 표시합니다. 로컬 서버가 꺼져 있으면 페이지가 보이지 않을 수 있으므로 서버를 먼저 실행하세요.

'네, 듣고 있습니다.' 버튼은 Mac의 한국어 **음성 합성**을 테스트합니다. 마이크 음성 인식/상시 호출어는 아직 없습니다.

두 번째 탭의 '화면 1장 확인' 버튼은 **ScreenCaptureKit으로 첫 번째 디스플레이 한 프레임만** 캡처해 화면에 표시합니다. macOS의 화면 녹화 권한 요청이 나타날 수 있으며, 거절 시 작동하지 않습니다. 사용자가 '지우기'를 누르면 앱에서 해당 이미지를 지웁니다.

**현재 절대 하지 않는 일:** 화면을 서버/클라우드/LLM으로 전송, 백그라운드 녹화, 파일이나 앱 조작, 대외 발행, 배포.

## 확인 기준

1. `swift build --package-path macos` 컴파일 성공 (GitHub Actions macOS 작업과 별도로 검증).
2. 사용자의 실제 Mac에서 창과 로컬 대시보드 표시.
3. 시스템 설정의 화면 및 시스템 오디오 녹화 권한 동의 후 스크린샷 표시/지우기 확인.
4. 한국어 음성 출력 품질 및 WebView 마이크 지원 여부 실기기 확인.

**주의:** SwiftPM의 `swift run`은 정식 서명/배포된 .app이 아닙니다. 배포용 Xcode 프로젝트·권한 설명·서명·업데이트는 다음 단계에서 별도로 처리해야 합니다.
