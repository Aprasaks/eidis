# JARVIS macOS Native Lab v0.3 — S1 Speech

> 상태: 기능 코드 작성, GitHub macOS 빌드 및 실제 Mac 권한 검증 필요. 완성된 개인 AI가 아닙니다.

## 요구 환경

- macOS 14 이상, Python 3, Swift 5.9+ / Xcode Command Line Tools
- 프로젝트 저장소 최상위 폴더에서 `START_JARVIS_MAC.command` 더블클릭
- 또는 터미널에서 `bash START_JARVIS_MAC.command` 실행

스크립트가 로컬 Python 서버를 실행하고, SwiftUI 코드를 빌드해 `dist/JARVIS.app`으로 묶은 뒤 열어 줍니다. 음성 인식 기능은 권한 설명이 포함된 `.app` 패키지에서만 활성화됩니다. 단순 `swift run`은 권한 설명이 없어 **음성 사용 금지** 상태로 실행됩니다.

## 구현 범위

- **자비스 탭**: 로컬 웹 UI를 표시하고 네이티브 음성 명령의 검증된 결과를 반영.
- **음성 탭**: 버튼을 눌러 한국어 음성 인식을 시작하고 ‘완료하고 명령 전달’을 누르면 종료, 인식된 문장을 로컬 API(`127.0.0.1:8765`)로 전송. HTTP 200 응답을 받은 경우에만 결과를 표시하고 한국어로 읽어 줌.
- **온디바이스 기본 정책**: `SFSpeechRecognizer.supportsOnDeviceRecognition`가 false이면 음성 인식을 수행하지 않음. Apple 서버로 음성을 보낼 수 있는 폴백은 없음. 지원 환경에서도 한국어 인식률은 실기기 테스트 필요.
- **화면 탭**: 명시적으로 누를 때 디스플레이 한 장을 캡처하고 Apple Vision으로 화면 속 한국어·영어 글자를 로컬에서 읽어 표시. AI 시각 추론/외부 전송/파일 저장 없음.
- **UI 구조 탭**: 실행 중인 앱을 직접 고른 뒤 접근성 권한을 요청하고 한 번만 UI 요소 역할과 일부 컨트롤 제목 읽기. 비밀번호/문서 제목/본문은 제외. 자세한 내용은 `docs/ACCESSIBILITY_S2.md`.
- **명령 해석**: 기존 로컬 규칙 기반 엔진만 사용. 자연어 LLM 판단 아님.

마이크와 음성 인식 권한은 첫 사용 때 macOS가 요청합니다. 화면 권한은 ‘화면 캡처 + 글자 읽기’를 직접 누를 때 확인하며, macOS 시스템 설정에서 별도 승인해야 할 수 있습니다. 시스템 설정 → 개인정보 보호 및 보안에서 권한을 확인할 수 있습니다.

## 확인 절차 (실제 Mac)

1. `START_JARVIS_MAC.command` 실행 후 네 탭과 웹 UI가 표시되는지 확인.
2. **음성** 탭에서 ‘마이크로 말하기’ 클릭 → 마이크 및 음성 인식 승인.
3. "자비스, 대시보드 띄워"를 말하고 ‘완료하고 명령 전달’을 누르기.
4. 음성 응답과 **자비스** 탭의 작업 화면 전환 확인.
5. **화면** 탭에서 ‘화면 캡처 + 글자 읽기’ → 권한 승인 → 이미지·인식된 글자 확인 → ‘지우기’.
6. 종료 후 로컬 서버가 종료되는지 확인.

온디바이스 한국어 음성이 지원되지 않으면 **음성 탭의 텍스트 명령**으로 흐름을 검증합니다. 오류/권한 문제는 추측하지 말고 정확한 메시지를 기록합니다.

## 화면 글자 질문 기능 v1.9

화면 탭에서 캡처와 OCR이 완료되면 **화면 글자에 질문하기 · 로컬 분석**에서 질문을 입력하고 **로컬 답변**을 누릅니다. 글자에서 오류·실패 문구를 찾거나, 질문의 키워드와 일치하는 문구를 표시하거나, 화면 글자 앞부분을 간단히 정리합니다. **음성으로 듣기**는 macOS 기본 TTS를 사용합니다. OCR 텍스트/질문은 외부 AI API, 로컬 Python 서버, SQLite, 로그로 보내지 않으며 Mac 앱 메모리에서만 처리합니다. 지우기를 누르면 인식 글자와 답변을 지웁니다. 이미지·아이콘의 의미 해석, 정확한 버튼 위치 추론, 오류 원인 확정은 지원하지 않습니다. 자세히: docs/SCREEN_QUESTIONS_V19.md.

## 선택 앱 UI 구조 질문 v2.0

**화면** 탭에서 대상 앱을 직접 선택한 후 **접근성 권한 요청** 및 **선택 앱 UI 구조 읽기**를 누르면 버튼·메뉴·탭과 입력 요소 종류만 읽습니다. 질문 창에서 "버튼이 뭐가 있어?" 같은 질문에 선택 앱의 UI 정보로 답합니다. 앱 선택을 바꾸면 오래된 결과를 지웁니다. OCR은 전체 화면, 접근성 UI는 선택 앱으로 서로 다른 범위입니다. 실제 버튼 클릭 및 화면 이해 AI는 수행하지 않습니다. 자세히: docs/UI_CONTEXT_V20.md.

## 중요한 제한

- ‘자비스’ 상시 호출 감지는 **미구현**, 사용자가 버튼을 눌러야 마이크 시작.
- 원격 LLM, 화면 이해, Mac 조작, 클라우드, iPhone, 자동 발행/삭제는 **미연결**.
- `dist/JARVIS.app`은 **로컬 개발용 임시 서명 앱**이고 공증·배포된 제품이 아닙니다.
- GitHub Actions에서 Swift 컴파일·앱 패키징을 확인해도 실제 Mac의 TCC 권한 승인·음성 정확도는 별도 실기기 확인이 필요합니다.
